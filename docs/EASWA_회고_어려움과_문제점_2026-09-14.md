| C-219 | **낡은 저장소 문서**를 근거로 「AI가 부호화 초벌을 했다」를 원고에 써 넣었다 |

나서는 이 갈래가 급격히 줄었다. 고정문서가 커진 이유가 이것이다.

대신 `_새판.hwp` 로 저장하는 쪽으로 바뀌었다.

## 5. 갈래 4 — 검사기가 거짓 통과·거짓 경보 (10건)

**내가 만든 검사기를 내가 통과했다.** 이 갈래가 가장 교활하다 — 통과했으니 안심한다.

| | 무엇 |
|---|---|
| F-313 | **내가 만든 검사기가 내 수정을 통과시켰다** |
| F-310 | 검사기가 부록을 못 찾아 「0건」으로 통과했다 |
| F-312 | 검사기 두 개가 **옛 원고(v16)** 를 보고 「위반 0」을 냈다 |
| F-318 | 문체 검사가 「연결하여」를 마무리 꼴로 잘못 세었다 |
| **F-332** | **지표가 한 번 맞았다고 신호라고 불렀다** — 「기타 비율」의 76%가 캡션이었다 |
| C-236 | 기준선 없이 「25건이라 가장 많다」를 결함으로 올렸다 |
| C-234 · F-329 | 기준 문서가 있는데 **우리 것만 재는** 검사를 만들었다 |
| (2026-09-14) | `check_circularity.py` 가 **폐기된 논리**를 아직 강제한다 |
| (2026-09-14) | `verify_manuscript_results_structure.py` 의 표 제목 계약이 v18 보다 낡았다 |
| (2026-09-13) | 서지 검증 1차가 **22건 오탐** — Crossref `issued` 를 출판 연도로 착각, 제목을 첫 마침표에서 자름 |

### 무엇이 공통인가

**검사기가 무엇을 못 보는지 안 적었다.** 그리고 **역치를 실측 없이 정했다.**

2026-09-13 에 셋을 실측으로 확인했다.

- 51편 p95 로 잡은 리듬 역치가 **267편에서는 96%를 걸렀다**
- 「기타 비율」의 84건 중 **64건이 캡션·제목·사사**였고 진짜 구어체는 0건
- `paper-proofread` 의 60자 역치는 **게재 논문 문장의 70%를 거른다**

### 지금 쓰는 규칙

1. 검사기마다 **「이 검사가 재지 못하는 것」**을 출력에 박는다
2. 역치는 **같은 분야 게재 논문 분포**에서 뽑는다. 손으로 정하지 않는다
3. **지표가 맞았을 때 왜 맞았는지 분해한다.** 한 번 맞은 것은 우연일 수 있다

## 10. 다음 논문에 가져갈 것

### 첫날에 하는 일

**고정문서부터 만든다.** 원고보다 먼저다. 넷만 있으면 된다.

1. **가진 자료** — 파일 경로까지. 「이 뒤에 필요해지는 자료가 있으면 그 주장은 못 쓴다」
2. **못 하는 주장** — 1번의 여집합이다. 자동으로 도출된다
3. **고정 수치** — 바꾸지 않는다
4. **장별 역할** — 무엇을 다루고 무엇을 안 다루나

EASWA 고정문서는 5만 자까지 자랐는데 **그 대부분이 「무슨 자료가 있는지 정리」**였다.
레포에 이미 있는 것(`docs/survey/RESULTS_*.md`, 커밋 이력, 분석 리포트)에서 뽑을 수 있다.

### 쓰는 동안

- **원자료를 연다.** 요약본·저장소 문서·기억으로 쓰지 않는다 (갈래 1)
- **「전수」라고 쓸 때 몇 개를 열었는지 함께 쓴다** (갈래 2)
