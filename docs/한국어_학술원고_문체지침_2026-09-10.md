# 한국어 학술 원고 문체 지침

EASWA 논문(현장과학교육 투고본)을 2026-09-10 에 정리하면서 실제로 측정하고 확정한 것이다.
감이 아니라 **같은 분야 게재 논문 12편에서 만든 기준선**이 근거다.

---

## 0. 먼저 알아야 할 것 — 에세이 기준을 쓰면 안 된다

`humanize-korean` 스킬이 들고 있는 실측 기준(KatFish 코퍼스)은 **칼럼·에세이·위키**다.
학술 논문에 그대로 대면 정상인 것이 AI 로 잡힌다.

| 지표 | 에세이 기준 | 한국어 학술논문 12편 |
|---|---|---|
| 쉼표를 가진 문장 | 사람 26.3% · AI 61.0% | 중앙값 **59.7%** (27.8~81.4) |
| 연결어미 뒤 쉼표 | 사람 4.1% · AI 19.8% | 중앙값 **14.0%** (11.0~20.9) |
| 문두 접속사 (천어절당) | 사람 0.43 | 중앙값 **2.47** (1.23~4.87) |

학술문은 열거가 많아 쉼표가 원래 많고, 「따라서」는 논리 연결자로 정상이다.
**장르가 다르면 기준선을 새로 만든다.** 만드는 법은 4절.

---

## 1. 기준선 — 한국어 과학교육 논문 12편 (천어절당·천문장당)

| 지표 | 최소 ~ 중앙값 ~ 최대 |
|---|---|
| 평균 문장 길이 | 11.4 ~ **24.9** ~ 43.1 어절 |
| 문두 접속사 (또한·따라서·즉·나아가·아울러·게다가·더욱이) | 1.23 ~ **2.47** ~ 4.87 |
| 부정 대구 (「A가 아니라 B」 + 「~은 아니다」) | 0.00 ~ **0.24** ~ 0.53 |
| ├ A가 아니라 B | 0.00 ~ **0.24** ~ 0.53 |
| └ ~은 아니다 | 0.00 ~ **0.00** ~ 0.15 |
| 마무리 꼴 (…을 보여준다 / …와 연결된다 / …로 볼 수 있다) | 0.00 ~ **0.82** ~ 1.96 |
| 「이는 ~」 (천문장당) | 0.0 ~ **13.8** ~ 74.4 |
| 100자 넘는 문장 (천문장당) | 189 ~ **393** ~ 581 |
| 문장당 쉼표 | 0.44 ~ **1.43** ~ 2.60 |
| 쉼표 구간 길이 | 4.0 ~ **11.4** ~ 14.0 어절 |

**「~은 아니다」는 12편 중 11편이 한 번도 쓰지 않는다.** 학술 논문은 유보를
「~에 한정된다」·「~까지는 다루지 않았다」·「~라는 한계가 있다」로 쓴다.

100자 넘는 문장은 **많을수록 사람 쪽**이다(에세이 코퍼스에서 인간 91.3 대 AI 8.1).
짧은 문장만 찍어내는 것이 AI 특징이므로, 길다고 무조건 자르지 않는다.

---

## 2. 판정은 밀도가 아니라 처방 역치로

밀도는 참고값이다. **실제로 손대야 하는 조건은 문단 단위 역치**다.

| 항목 | 손대는 조건 |
|---|---|
| 문두 접속사 | 한 문단에 3회 이상 |
| 「이는 ~」 | 한 문단에 3회 이상 |
| 같은 종결어미 | 한 문단에 4문장 연속 |
| 부정 대구 | 인접한 두 문장이 모두 대구 (연쇄) |
| 「즉」 | 문서 전체 2회 이하로 |

**문서 전체를 훑어 일괄 제거하지 않는다.** 접속사 한두 개는 사람 글에도 있고,
「이는 ~」은 앞 문장을 받는 정상적인 한국어 담화 장치다. 걷어내면 논리가 끊긴다.

부정 대구도 마찬가지다. 출현 수보다 **연쇄**가 신호다. 사람 필자도 다용하지만
문서 전반에 산포하고 사이에 다른 수사가 끼어든다.

## 3. 쓰는 규칙

### 3.1 문장 — 실제 한 것 먼저

> ① 실제 수행·관찰 → ② 적용 범위 → ③ 정말 필요할 때만 짧은 부정

| 고칠 꼴 | 대신 |
|---|---|
| A가 아니라 B다 | B다 |
| A를 할 것이 아니라 B를 | B를 먼저 정한다 |
| 이는 …임을 보여준다 | (관찰문을 그대로 쓴다) |
| …와 연결된다 / 맞닿아 있다 | 「…의 관점에서 보면 …」 또는 문헌을 주어로 |
| A를 넘어 B | B |
| A할 뿐 B하지 않는다 | 이 틀로 A는 할 수 있지만 B는 별도로 필요하다 |
| ~할 필요가 있다 (반복) | 한 문단에 한 번까지 |
| 명사구 여섯 개 병렬 | 「여섯 가지였다」+ 서술문 여섯 |

**남겨야 하는 부정도 있다.** 「검증한 결과가 아니다」·「비교하는 값이 아니다」처럼
못 하는 주장을 막는 유보는 지우면 안 된다. 다만 **주장을 남기라는 뜻이지 문법까지
남기라는 뜻은 아니다.** 「~에 한정된다」·「~는 범위에 포함하지 않았다」로 바꾸면 된다.

### 3.2 목차·절 제목 — 이름을 붙이고 주장을 하지 않는다

| 고칠 꼴 | 예 | 대신 |
|---|---|---|
| 대시(—) 부제 | 「왜 며칠 앞인가 — 오늘 밤 정보밖에 없다」 | 「다일 예보의 필요」 |
| 단정형 「~다/했다」 | 「아카이브를 직접 지었다」 | 「아카이브 구축」 |
| 부정으로 끝내기 | 「누수가 없다」 | 「시간 블록 교차검증」 |
| 의문형 「왜 ~인가」 | 「왜 v12 전용인가」 | 「v12 로 한정한 이유」 |
| 대구 | 「무엇이 되고 무엇이 안 되나」 | 「결과의 적용 범위」 |
| 결과 수치 | 「6칸 중 2칸만 통과」 | 「주변보정 결과」 |

**소제목은 명사구다.** 결론 문장을 제목 자리에 두지 않는다.
영문 저널이면 한국어 제목이 번역 발판이므로, 발판이 수사적이면 영어도 물려받는다.

## 4. 재는 법

두 스크립트가 있다. 다른 저장소에서도 경로만 바꿔 쓰면 된다.

```

C:\Users\bmffr\Desktop\Result\EASWA_ExploringAllSkyWebApp\docs\check_style_freq.py
```

### 4.1 기준선 만들기

`build_style_baseline.py` 의 `CORPUS` 에 **같은 분야·같은 학회지 게재 논문 PDF** 를
열 편 넘게 넣는다. 그 논문들에서 지표를 재어 최소·중앙값·최대를 낸다.

같은 잣대를 쓰려고 **자기 원고도 md 가 아니라 조판 PDF 에서** 뽑는다. PDF 본문에서
「다.」로 끝나고 한글이 절반 넘는 다섯 어절 이상 문장만 세고, 참고문헌은 자른다.

**장르가 바뀌면 기준선을 새로 만든다.** 영문 저널 논문에는 이 지표가 안 맞는다.
그 저널 게재본으로 다시 만들거나, 문체 지표는 접고 3.2 의 목차 규칙만 쓴다.

### 4.2 원고 재기

```
python -X utf8 docs/check_style_freq.py --humanize
```

되풀이·접속어·끝 단어·부정 대구를 자리까지 찍고, 마지막에 실측 기준값과 견준다.

## 5. 검사기 규약 — 이번에 세 번 조용히 통과했다

| 무슨 일이 있었나 | 왜 |
|---|---|
| 용어표를 0줄 읽고 「0건 통과」 | 부록 제목이 「# 부록 A」에서 「# 부록」으로 바뀌었다 |
| 캡션을 0개 읽고 「0건 통과」 | 표 번호가 「표 3-1」에서 「표 1」로 바뀌었다 |
| 본문을 다 걷은 뒤에도 대구가 남음 | 캡션을 검사 범위에서 빼 두었다 |

셋 다 같은 실패다 — **무엇을 몇 개 읽었는지 안 찍었다.**

1. **검사기는 읽은 개수를 먼저 찍는다.** 「캡션 17개(표 12·그림 5)」처럼.
2. **0 이면 통과가 아니라 실패다.** 원고에 있어야 할 것이 0 이면 정규식을 의심한다.
3. **캡션·표 제목·주석도 검사 범위에 넣는다.** 사람이 읽는 문장이다.
4. **원고 형식(번호 체계·제목·부록 구조)을 바꾸면 검사기 정규식을 먼저 확인한다.**

## 6. 에이전트 행동 규칙

이번에 사용자가 직접 고친 것들이다.

- **지어낸 문장은 표시한다.** 편집 스크립트 주석과 보고에 「이 문장은 내가 썼다」를
  남긴다. 원어민 교정·최종 확인 때 그 자리만 보면 된다.
- **내가 만든 문제는 내가 고친다.** 「어느 쪽으로 할까요」로 넘기기 전에, 그것이 내가
  넣은 오류인지 본다. 맞으면 고쳐 놓고 확인을 구한다.
- **세어 보고 말한다.** 「많다/적다」를 기준 없이 말하지 않는다. 기준선이 없으면
  먼저 만든다.
- **측정 도구부터 의심한다.** 이상한 값이 나오면(113어절 한 문장, 0건 통과) 원고가
  아니라 파서를 먼저 본다.
- **원고는 하나만 고친다.** 조판본을 직접 고쳐 원고에 되돌리지 않는다. 조판 산출물
  이름이 둘로 갈리면 버전 누락이 문체보다 위험하다.
- **문장은 원고 주인이 쓴다.** 에이전트는 사실 확인·제약 점검·검사를 맡는다.
  문안을 낼 때는 「후보」로 내고 원고에 바로 넣지 않는다.

## 7. 한 번에 다 하려 하지 않는다

EASWA 는 네 회차로 나눠 고쳤고 회차마다 다시 쟀다.

| 회차 | 무엇 | 부정 대구 | 마무리 꼴 |
|---|---|---|---|
| 시작 | | 3.03 | 1.38 |
| 1차 확정 문안 20곳 | 초록·4.5·5.5·결론 | 2.15 | 1.38 |
| 2차 5장 12곳 | 5.1~5.4 전체 | 2.15 | 0.31 |
| 3차 부정 대구 11곳 | 요약·1.2·2.1·2.3·4.1·4.3·4.4·5.5·결론 | **0.44** | 0.94 |
| 4차 서론·3.1·결론 5곳 | 명사구 병렬·「필요가 있다」 | 0.44 | **0.73** |

**수치를 맞추려고 자연스러운 문장까지 뜯지 않는다.** 범위 안에 들어오면 닫는다.
그다음은 조판·분량·학회 형식이다.
