# B. 앞선 토론의 판정

## B-1. 반대 하나 — 3.4 문단 전체 삭제

심사 근거는 「3.6 에서 자동저장 사실을 안내했다고 이미 밝힌다」이다. 두 곳을 열어 보면
**대상과 방법이 다르다.**

- **3.6** — 「두 조사 모두 시작 전에 … 수행 기록이 연구자가 관리하는 저장소에 자동
  저장된다는 점도 **구두로** 함께 안내하였다」 → **연구 참여자 26명**에게 구두로
- **3.4** — 「탐구 화면에는 … 고지를 **상시 표시**하여, **공개 운영 중 접속한 사용자**에게도
  같은 내용이 보이도록 하였다」 → **일반 방문자**에게 화면으로

플랫폼이 공개 운영 중이고 익명 기록을 받는다. 3.4 를 통째로 지우면 **일반 방문자용
고지가 원고에서 사라진다.** 2026-09-06 심사가 확인 항목으로 올렸던 바로 그 지점이다.

심사 자신도 항목 2-4 에서 「개인정보·자동저장 고지는 서비스 구현 설명이므로 유지
가능」이라 쓰고 3.4-4 에서 뒤집었다. 삭제 근거로 든 「해석·기록 기능은 4.3 과 그림 5 에
있다」도 대상이 어긋난다. 3.4 문단은 기능 설명이 아니라 저장·고지 설명이다.

**연구 근거로 썼다는 문장은 이미 지웠다. 남은 것은 고지 사실뿐이므로 유지한다.**

## B-2. 조건이 「유지」로 풀리는 것 — 부록 「미귀속」 행

심사는 실제 응답이 없으면 지우라 했다. 4.6 에 「자료 분해능·이상치·**측광 과정 일반**에
관한 응답도 있었다」가 있고 부록의 미귀속 예시가 「측광 과정에서의 오류」다.
**응답이 있으므로 남긴다.**

## B-3. 결론은 맞고 근거가 틀린 것 — 표 3 SIMBAD

심사는 1.2 와 내부 충돌이라 한다. 1.2 는 「식별 정보와 좌표, 문헌 및 측정 정보를 제공」,
표 3 은 「광도 등 미제공→환산」이다. **정면 충돌은 아니다** — SIMBAD 는 등급은 주고
시계열 광도곡선은 주지 않는다. 다만 「광도 등 미제공」이 **부정확한 것은 맞다.**
심사 대안 문구를 쓴다.

## D-1. 문법이 어긋난 것 — 셋

### ① 3.4 주어와 서술어가 안 맞는다
> **사용자는** 별도 프로그램 설치 없이 브라우저로 접속하도록 **구성하였다.**

→ 「별도 프로그램 설치 없이 브라우저에서 사용할 수 있도록 구성하였다.」

### ② 1.2 주어와 서술어가 안 맞는다
> WorldWide Telescope 기반 교육 프로그램 …, SDSS Voyages, ESA CESAR, Rubin

> 여럿임을 **알 수 있다.**

프로그램이 「알 수 있다」가 된다.
→ 「… 실제 자료를 특정 학습 주제와 연결하는 다양한 교육 환경이 개발되어 왔다.」
