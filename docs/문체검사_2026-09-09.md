# v17 문체·빈도 검사 (2026-09-09)

소유자 요청 — *「문장, 문체, ai문체, 빈도수 점검」*. **검사만 했고 원고는 고치지 않았다.**

## 잰 방법

| | |
|---|---|
| 대상 | `EASWA_논문_v17.md` 의 한국어 산문 — 문단 112 · 문장 354 · 28,396자 |

**기준선의 한계를 먼저 밝힌다.** metrics_v2 의 v2 지표 14개는 기준값이 전부
`_placeholder: true` 다(`baseline_v2.json` 의 `calibration_due`). 그 z 값은 근거로 쓰지
않았다. 실측 기준이 있는 것은 **쉼표 네 지표뿐**이고, 그것도 장르가 에세이라
학술 논문에 그대로 맞지는 않는다. 학술문은 열거가 많아 쉼표가 원래 많다.

## 눈에 띄는 것 셋

### 1. 쉼표 — 네 지표 중 셋이 LLM 쪽

| 지표 | 이 원고 | 사람 | LLM |
|---|---|---|---|
| 쉼표를 가진 문장 비율 | **61.6%** | 26.3% | 61.0% |
| 쉼표 구간 길이 | **8.17어절** | 4.35 | 8.56 |
| 연결어미 뒤 쉼표 비율 | 13.3% | 4.1% | 19.8% |
| 문장당 쉼표 수 | 1.27개 | 1.13 | 2.56 |

연결어미 뒤 쉼표(`~하고,` `~하며,` `~지만,`)가 60회, 문장 여섯 개에 한 번꼴이다.
가장 몰린 곳은 2.2 · Ⅵ장 · 2.3.

다만 쉼표가 많은 문장 여덟 개를 열어 보니 대부분 **내용 열거**였다 — 설계 원리
다섯, 변수 목록, 인용 나열. 줄일 수 있는 것은 열거가 아니라 접속 쉼표 쪽이다.

### 2. 다섯 설계 원리를 통째로 나열한 문장이 넷

요약 · 3.6 · 4.3 · Ⅵ장에 「탐구 주제 중심 접근, 기술 실행 부담 완화, 분석 과정의
가시화, 결과 해석의 학습자 수행, 수업 적용 가능성 지원」이 그대로 되풀이된다.
요약의 두 번째 문장과 Ⅵ장 「둘째」가 거의 같은 문장이다(48어절). 다만 결론이
초록과 겹치는 것은 논문의 형식이므로 이것만으로 흠이라 하기 어렵다.

「기술 실행 부담」 6회 · 「일곱 단계 공통 탐구」 5회 · 「공공 천문자료를 학교」 4회도
같은 뭉치에서 나온다.

### 3. 대구 「A가 아니라 B」 12회

분류 체계가 **실측 최강 신호**로 표시한 항목(C-8)이다. 문장 29개에 한 번.
12곳을 다 열어 보니 절반쯤은 범위를 못박는 실제 일을 한다 —
「코드의 정확도 검증이 **아니라** 민감도 점검」, 「이론이 **아니라** 1차 자료에서」.
그래도 4.4 한 절에만 두 번 있고, 요약·1.1·2.1·3.5·3.6·4.1·4.3·5.3·Ⅵ에 고루 퍼져 있다.

## 정상으로 보이는 것

- **리듬**: 문장 길이 평균 18.6어절, 표준편차 8.8, 변동계수 **0.47**. 0.4 아래면
  기계적으로 고른 리듬(E-1)인데 그 위다.
- **문단 길이**: 평균 3.2문장, 1~7문장으로 흩어져 있다. 「모든 문단 3~4문장」 공식(E-3) 아님.
- **종결 표현**: 155가지, 상위 8개가 30%. 같은 종결이 4문장 이상 잇달아 오는 곳은 두 곳뿐
  (Ⅵ장의 「있다」 4연속, 5.5의 「없다」 4연속).
- **피동**: 「~에 의해」 0회 · 이중 피동 0회 · 「되어진다」 0회.
- **번역투 대부분 낮다**: 「~에 있어」 0 · 「가지고 있다」 0 · 「만들어지다/이루어지다」 1 ·
  「~을 바탕으로」 2 · 「~를 통해」 4.
- **AI 관용구 없음**: 「요컨대·결론적으로」 0 · 「의의가 크다」 0 · 「향후·앞으로」 0 ·
  「과제도 남아 있다」 0 · 이모지·불릿 남용 없음.

### 접속어 — 문장 첫머리 39곳 (문장 9개당 1회)

처음에 23곳이라 했는데 「다만·특히·즉·이때」를 목록에서 빼 두었던 탓이다.

| 접속어 | 횟수 | 퍼져 있는 절 |
|---|---|---|
| 따라서 | 12 | 1.1 · 2.1 · 2.2 · 2.3 · 3.5 · 4.4 · 4.6 · 5.1 · 5.2 · 5.4 · 5.5 |
| 다만 | 11 | 1.2 · 2.1 · 2.2 · 2.3 · 4.3 · 4.4 · 5.2 · 5.3 · Ⅵ |
| 또한 | 5 | 1.2 · 5.5 · Ⅵ |
| 한편·특히 | 각 3 | |
| 즉·그러므로·그러나·이때·반면 | 각 1 | |

**둘이 3분의 2다.** 「따라서」와 「다만」이 23곳. 특히 5장에 「따라서」가 네 절에 걸쳐 있다.

### 문구 끝 단어

어미 뭉치로 묶으면 「~하였다」 105회(29.7%) · 「~있다」 33회 · 「~한다」 31회.
낱말 그대로는 155가지로 흩어져 있다.

같은 끝 단어가 잇달아 오는 곳은 두 군데다.

- **5.5** — 「없다」 4연속
- **Ⅵ장** — 「있다」 4연속. 넷 중 셋이 「~할 수 있다」다

### 되풀이되는 말

- 「탐구 주제 중심 접근, 기술 실행 부담 완화, …」 다섯 원리 통째 나열 4회
- 「확인할 필요가 있다」 4회 · 「일곱 단계 공통 탐구」 4회 · 「기준값 비교 화면의」 4회
- 문장 첫머리 — 「본 연구는」 4회 · **「다만 이」 4회** · 「두 조사」 4회 · 「따라서 실제」 3회

### 「A가 아니라 B」·「~것은 아니다」 20곳 (문장 18개당 1회)

처음에 12곳이라 했는데 「~것은 아니다」 꼴을 빼 두었던 탓이다. 둘은 같은 버릇이다.

한 절에 몰린 곳: **4.4 세 곳 · 1.2 세 곳 · 5.5 두 곳 · 2.1 두 곳 · 3.5 두 곳.**

절반쯤은 범위를 못박는 실제 일을 한다(「코드의 정확도 검증이 아니라 민감도 점검」).
나머지는 앞말을 부정했다가 다시 세우는 같은 리듬이 되풀이된다.

쉼표 지표가 LLM 쪽으로 나오는 것은 판정 근거로 쓰지 않는다. 비교 기준이
**에세이·시** 코퍼스이고 학술 논문은 열거가 많아 쉼표가 원래 많다.
