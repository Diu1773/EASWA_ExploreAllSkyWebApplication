# 탐구 흐름 전체 캡처 — 외계행성 식현상 탐구블럭

> 촬영 2026-08-11 · 라이브 https://easwa-webapp.onrender.com · 폭 1440
> 대상 **WASP-6 b** (번들 예제 — 교사 시연 20건 중 14건이 이 대상)

## 실제로 수행한 분석이다

화면만 넘긴 것이 아니라 **차등측광과 모델 적합을 끝까지 돌렸다.**
그래서 Step 5·6 에 들어 있는 값은 실측이다.

| 산출값 | 이 캡처 | 교사 시연 실측(14건) |
|---|---|---|
| Rp/R* | **0.1453** ± 0.0059 | 중앙값 0.1457 |
| 식 깊이 | 2.112 % | — |
| χ²_red | 0.96 | 중앙값 0.90 |

교사 12인이 얻은 중앙값과 0.0004 차이다 — 같은 경로로 같은 결과가 나온다는 뜻.

## 화면 구조 — 스텝이 두 겹이다

블럭이 **7단계**(Step 0~6)이고, 그중 **Step 4 안에 Lab 이 통째로 들어 있으며
Lab 은 자체 6단계**를 갖는다. 화면 하단에 «정밀 분석(Lab)에서 모델 적합까지
마치면 다음 단계가 열립니다»라고 안내된다.

- Step 0~4 는 URL 로 바로 접근된다 (`?blockStep=…&target=wasp_6_b`)
- **Step 5·6 은 URL 로 못 간다** — 적합 결과가 있어야만 열린다
  (`maxUnlockedStepIndex={fit ? undefined : 4}`)

## 담기지 않은 것

- **성단 CMD · KMTNet 모듈의 Step 1~6** — 구조는 같은 공용 워크플로지만 대상 선택과
  자료 적재 경로가 달라 별도 구동이 필요하다. Step 0 은 상위 폴더에 있다.
- **로그인 상태 화면** — `/my`, `/records/:id` 는 Google 로그인이 필요하다.
