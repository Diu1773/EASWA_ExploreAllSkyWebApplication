## 2. 「60자 초과 분리 권고」는 역치가 틀렸다

`rules_ko.md` 점검2 가 60자 초과를 🔵 분리 권고로 잡는다. 우리 원고에서 **216건(61%)** 이
걸린다. 같은 잣대를 게재 논문 267편 34,028문장에 대 봤다.

| 역치 | 게재 논문이 걸리는 비율 | 이 원고 |
|---|---|---|
| **60자** | **70.0%** | 60.5% |
| 80자 | 49.5% | 47.1% |
| 100자 | 32.5% | 33.6% |
| 120자 | 20.8% | 21.0% |
| 150자 | 10.7% | 11.8% |

게재 논문 문장의 중앙값이 **80자**다. 60자 역치는 게재 논문 열에 일곱을 거른다.

**그리고 이 표가 말하는 더 중요한 것** — 이 원고의 문장 길이 분포는 네 역치 모두에서
게재 논문과 2%p 안쪽으로 겹친다. **문장 길이로는 손댈 것이 없다.**

### 내가 두 번 틀렸다

1차 조회에서 **22건**이 걸렸다(연도 불일치 11 · 못 찾음 11). 표본 8건을 직접 확인하니
하나도 오류가 아니었다.

| 무엇을 틀렸나 | 왜 |
|---|---|
| 연도 불일치 11건 | Crossref `issued` 는 **온라인 공개 연도**다. Baines 는 `issued=2016·print=2017` 이고 **원고의 2017이 맞다.** `published-print` 로 바꾸니 11→2 |
| 못 찾음 11건 | 서지 파서가 제목을 **첫 마침표에서 잘랐다.** 「Gaia Data Release 3: Summary…」가 「Gaia Data Release 3」로, 「ExoClock Project. III. 450 new…」가 「ExoClock Project」로. 둘 다 실은 DOI까지 확인되는 문헌이다 |

**서지 검증 도구는 자기 오탐률을 먼저 재야 한다.** 안 재고 냈으면 「환각 의심 11건」이라는
보고서가 나갔을 것이다.

### 할 일

1. `rules_ko.md` 규칙을 코퍼스로 걸러 `check_ko_rules.py` 를 만든다. 살아남은 10개 +
   맞춤법 표. 규칙마다 「267편 중 N편」을 붙여 출력한다. MIT 고지를 넣는다.
2. 문장 길이 역치를 60자에서 **분포 백분위**로 바꾼다. 절대 역치는 학술지마다 틀린다.
3. 용어 일관성 검사를 우리 쪽에 넣는다. 코드 몇 줄인데 없었다.
4. 서지 검증은 **`published-print` 우선 + 제목 전체 파싱 + arXiv 폴백** 셋을 반드시 갖춘다.
   셋 중 하나만 빠져도 오탐이 20%를 넘는다.
