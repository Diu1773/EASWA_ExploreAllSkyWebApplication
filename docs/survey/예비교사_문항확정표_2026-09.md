# 예비교사 문항 확정표 — 연구 논리와 응답 해석

2026-09-06 실제 폼 수정 기준. [반영·검증 기록](예비교사_폼반영기록_2026-09-06.md)의 문구·설정이 현재 기준이다. 기존 문서의 예상 점수·집단 특성 단정·0.3점 기준·Q6을 EASWA 개선 효과로 읽는 설명은 제거하였다.

## 이 조사가 연구문제에 기여하는 방식

논문의 흐름은 기존 서비스와 이론 검토 → 설계 원리·자료 선정 → 구현 → 현직교사 검토 → 보완 → 예비교사 재평가이다. 이번 설문은 연구문제 4의 보완본 반응과 남은 보완 요구를 수집한다. 설계 원리 자체의 타당성이나 학습 효과를 이 설문만으로 입증하지 않는다. 예비교사는 학교 학생과 동일한 집단이 아니므로 일반 중고등학생의 학습 효과로 일반화하지 않는다.

| 연구문제 | 논문의 주된 근거 | 이번 설문의 역할 |
|---|---|---|
| 1. 기존 서비스 활용 장벽·설계 시사점 | 실제 서비스 사례분석 | Q5·Q6의 기존 서비스 경험·예상을 맥락 자료로 사용. EASWA 개선 효과와 구별. |
| 2. 설계 원리·탐구 주제와 자료 선정 | 이론적 배경 및 사례분석, 자료 선정 기준 | 원리를 새로 도출하거나 검증된 척도로 확정하는 자료가 아님. |
| 3. 프로토타입 구현 | 구현 기능·흐름·화면과 기술적 산출값 점검 | 기능에 대한 사용자 반응은 보조 자료. 수치 정확도·개발 정합성을 설문 점수로 검증하지 않음. |
| 4. 사용자 검토와 보완 | 현직교사 원문·정량 반응 → 선정 근거·실제 보완 → 예비교사 재평가 | 설계 의도가 어떻게 경험되는지, 어느 요소에 도움·보완이 필요한지 파악. |

## 다섯 설계 원리와 문항의 연결

원리 하나에 여러 문항이 연결되지만 합산하여 검증된 ‘원리 점수’를 만들지 않는다. 각 진술이 묻는 범위와 자유응답의 구체 경험을 함께 제시한다.

| 설계 원리 | 핵심 문항 | 응답으로 확인할 내용 | 보조 자료와 한계 |
|---|---|---|---|
| 1. 탐구 주제 중심 접근 | Q8 | 천체명·자료 검색보다 주제·질문에서 시작하는 구성이 인식되는가 | Q19·Q20의 진입·주제 단계 경험. 탐구 질문 생성 능력 검사가 아님. |
| 2. 기술 실행 부담 완화 | Q9 | 별도 코딩 환경 없이 분석 흐름을 따라갈 수 있는가 | Q7·Q7-1·Q19·Q20의 수행 범위·자기보고 시간·어려움. 용어 이해가 쉬워졌다는 뜻까지 포함하지 않음. |
| 3. 분석 과정 가시화 | Q10·Q11·Q14 | 출처·관측 정보, 조정 가능한 조건, 광도곡선·적합 결과가 확인·해석 가능하게 제시되는가 | Q18-2의 용어·그래프 경험. 정보가 존재하는 것과 학습자가 이해하는 것은 다름. |
| 4. 결과 해석은 학습자가 수행 | Q15(역)·Q16·Q18-1 | 무엇을 해석할지 명확한가, 산출값–기준값 차이를 스스로 해석하도록 돕는가 | Q20-1의 차이 원인 설명. 문장 응답만으로 실제 개인의 모든 해석 능력을 판정하지 않음. |
| 5. 수업 적용 가능성 지원 | Q13·Q17 | 단계 질문이 수행을 돕는가, 학교 천문탐구 활동에 적절해 보이는가 | Q21·Q22·Q23의 자료·선수지식·난이도·교사 지원 조건. 실제 학생 수업 효과는 후속 검증. |
| 여러 원리에 걸친 사용 부담 | Q12(역) | 화면 복잡성이 탐구 흐름 파악에 부담이 되는가 | Q18-2·Q19·Q20으로 문장·단계·개념·실행 부담을 구분. 전체 디자인 재설계 필요로 자동 판정하지 않음. |
| 종합 판단·활용 의향 | Q18·Q21-1 | 교육용 플랫폼으로의 종합 판단과 본인의 향후 활용 의향 | 원리별 합격 판정이나 실제 사용 행동이 아님. |

설문 안내에는 목적과 응답 대상을 설명한다. ‘원리 2가 잘 실현됐다’ 같은 기대 결론이나 긍정 응답을 유도하는 논리를 참여자에게 먼저 제시하지 않는다. 원리–문항 대응과 해석 경계는 연구자용 문서에 명시한다.

## 배경·수행·서술 문항의 용도

| 문항 | 받는 정보 | 분석 규칙 |
|---|---|---|
| 회차·Q1 | 회차와 전공 | 제출시각만으로 시연 참가 여부를 단정하지 않고 참가 기록과 함께 구분. |
| Q2·Q2-1 | 천문 경험, 고교 물리·화학·생명과학·지구과학 이수 | 배경 기술용. Ⅰ·Ⅱ 통합, 학업 성취나 능력 점수로 환산하지 않음. |
| Q3·Q3-1·Q4 | 실제 자료·웹 도구 경험, 활용 이유 | 미경험자의 기존 서비스 응답은 예상일 수 있음을 명시. |
| Q5·Q6 | 기존 서비스의 장벽과 이유 | 명시적으로 EASWA를 언급한 원문은 그 대상 차이를 남김. 전체를 EASWA 불만으로 분류하지 않음. |
| Q7·Q7-1 | 직접 수행한 범위와 자기보고 소요시간 | 완료자·부분 수행자·미수행자를 구분. 시간은 로그로 잰 순수 실행 시간이 아님. |
| Q18-2 | 용어·그래프·안내 문장·단계 질문 찾기의 도움 필요 경험 | 4행×5범주로 별도 빈도 보고. 도움의 서열 점수화 금지. |
| Q19·Q20 | 본인의 어려움 단계와 구체 막힘 | 학생이 어려울 것이라는 예측과 본인 경험을 섞지 않음. |
| Q20-1 | 기준값 차이 원인의 설명 | 수행 범위·자료 품질·분석 조건·모델 가정을 구분. 원문 근거와 무응답을 모두 보존. |
| Q21 | 중요하다고 생각하는 보완 요소 | 복수선택 빈도이며 우선순위 순위투표가 아님. 없음·판단 불가와 중복 선택을 구분. |
| Q22·Q23 | 걱정·이유, 장점·보완 요구·기타 의견 | 모든 서술형을 문항·응답자별로 읽고 필요하면 의미 단위로 나눔. 장점을 개선 요구로 바꾸지 않음. |

## 역문항과 보고 규칙

Q12 ‘화면 구성은 복잡하여 … 어렵다’, Q15 ‘기준값 비교 화면은 … 파악하기 어렵다’는 원점수가 높을수록 부담이 크다. 다른 문항과 방향을 맞출 때만 6에서 원점수를 뺀다. 응답 화면에는 역채점을 안내하지 않고 모든 문항에 동일한 동의 방향을 유지한다.

Q18-1은 Q15와 관련된 긍정 진술로, 척도 끝에서 별도로 묻는다. 두 문항의 불일치는 문구 이해·경험 차이를 재검토할 단서다. 자동 응답 제외나 ‘역문항 효과가 검증됐다’는 판단 근거가 아니다. 미수행·판단 불가 응답을 억지로 평정시키지 않는 것, 문장을 끝까지 읽도록 안내하는 것, 어려움의 구체 서술을 함께 받는 것을 함께 적용했다. 역문항의 한계에 관한 문헌과 범위는 반영 기록에 제시했다.

문항별 1–5 분포·유효 응답 수·무응답 수를 먼저 제시하고 필요시 평균·표준편차를 보조한다. 무응답을 0점·중립으로 대치하지 않는다. 1차와 문장 자체를 유지한 반응 문항은 Q8–16·Q18의 10개이나 도움말·필수 여부와 참가 집단·배포본이 달라 조사 조건의 동일성이나 인과 효과를 주장하지 않는다. Q17·Q21-1 변경 및 Q18-1·Q18-2 신설은 따로 보고한다.

긍정 반응이 많아도 구체적 보완 요구는 검토한다. 반대로 낮은 상대 평균 하나만으로 개선 항목을 확정하지 않는다. 실제 변경은 현직교사 원문과 연구자의 판정, 해당 설계 원리, 시연 전 가능한 범위, 배포본의 실제 반영을 연결하여 설명한다.
