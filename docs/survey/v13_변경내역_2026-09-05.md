## 2. 조사가 연구문제에 답하는 구조를 결과 절에 넣었다

**표 4-12(신설). 설계 원리별 검토 결과.** 종전 4.5 는 문항별 점수만 있었고 «어느 원리가 확인되었나»가
없었다. 원리마다 대응 척도 문항, 함께 확인한 자료(어려움 단계·보완 요구·앱 로그), 판정을 한 줄로 놓았다.

| 원리 | 판정 |
|---|---|
| 탐구 주제 중심 접근 | 단일 문항 측정이므로 반응 경향으로만 기술 |
| 기술 실행 부담 완화 | **확인** (척도 4.50 + 완주 9/12 + 로그 적합 14건) |
| 분석 과정의 가시화 | 화면 구성 수준에서 확인, **용어 수준은 부족**(자유응답 11명) |
| 결과 해석의 학습자 수행 | **보완 대상** (최저 3.42 + 보완 요구 상위) |
| 수업 적용 가능성 지원 | 단일 문항 측정이므로 반응 경향으로만 기술 |
| 사용 부담(역문항) | 보완 후보 |

판정 어휘를 셋으로 제한하고 그 뜻을 표 주에 적었다. 이 표가 들어가면서 이후 표 번호가 하나씩 밀렸다
(옛 4-12 자유응답 → 4-13, 보완 내역 → 4-14 … 개선 방향 → 4-18). 본문 참조도 전수 확인했다.

**「쉽게」의 증거를 한 문단에 모았다.** 종전에는 자기보고 점수 하나만 결론에 인용되고 나머지 증거가
4.5·4.7.2 에 흩어져 있었다. 이제 완주 9/12, 10~30분 8명, 적합 14건의 반지름비가 기준값과 0.0003 차이,
번들 밖 대상 5명, 측광 수 초·적합 2~3초를 한 문단에서 잇고, 같은 과제를 기존 서비스로 한 비교가
없다는 조건을 함께 적었다. 6.1 결론의 넷째 문단도 이 내용으로 다시 썼다.

## 3. KMTNet 모듈을 개발이 끝난 것처럼 적고 있었다

**확인한 코드 사실**(2026-09-05, 저장소 실물)

| 항목 | 실제 |
|---|---|
| 광도자료 | KMTNet 공개 아카이브의 관측소별 측광 결과 테이블 `.pysis` 를 내려받아 파싱 (`kmtnet_lightcurve_service.py`) |
| 학습자가 실행하는 계산 | 관측소별 곡선 병합 + 미시중력렌즈 모델 적합(t0·u0·tE) |
| **측광** | **수행하지 않는다.** 영상에서 밝기를 재는 단계가 없다 |
| 관측 프레임 목록 | KASI 원격 조회 실패 시 **합성 대체**(`_build_synthetic_observations`) |
| 차분영상 화면 | **생성한 예시 이미지**(`_render_preview_frame`·`_encode_difference_image`) |
| 정렬 단계 | `reference_frame_index` 는 실제 계산에 쓰이지 않음(코드 주석: unused) |

옛 표 4-6 은 «관측 프레임 확인·정렬 → 차분영상 확인 → **관측소별 광도 추출** → 다지점 병합 → 모델 적합»
이라고만 적어, 식현상 모듈과 같은 수준으로 읽혔다. v13 은 이렇게 고쳤다.

- 표 4-6 에 **「학습자가 실행하는 계산」·「제공 자료의 형태」·「개념 시연으로 구성한 부분」 세 행을 신설.**
- 4.4 의 KMTNet 문단에 **두 모듈의 계산 범위 차이를 문단 하나로** 서술. 식현상은 원시 영상에서 산출값까지,
  KMTNet 은 공개 측광 테이블에서 병합·적합까지. 그 차이가 **두 자료원의 공개 형태에서 온다**는 점도 적었다.
- *«식현상 모듈과 같은 수준으로 분석 과정 전체를 학습자가 수행하는 모듈은 아니다»* 를 명시.
- 5.5 의 확장 가능성 서술에도 **세 모듈의 구현 깊이가 다르다**는 문단을 넣어, 확인된 것이 구조적 확장
  가능성이지 세 주제에서 같은 수준의 탐구가 구현되었다는 뜻은 아님을 밝혔다.

## 4. 성단 CMD 모듈이 2026-09-05 변경 이전 서술이었다

옛 문단은 «색등급도를 그리고 전향점 위치와 시차 기반 거리를 문헌값과 비교»까지만 적혀 있었다.
9월 5일에 등시선 맞추기로 바꾼 것이 반영되지 않았다.

- PARSEC v1.2S 등시선(Gaia EDR3 측광계)을 겹쳐 **나이·거리지수·소광·금속함량 네 값을 조절**해 맞춘다.
- 소광 계수는 Wang과 Chen(2019), 모델 가정(초기질량함수·쌍성·자전 미고려)은 화면에 표시.
- **네 값이 서로 보상되므로 겹침이 좋다고 각 값이 옳은 것은 아니라는 안내**도 화면에 있다는 사실을 적었다.
- **구성원 선별 조건(시차·고유운동 창)은 서버 고정**이라 학습자가 못 만진다는 것도 적었다.
- **이 기능은 1차 검토 이후 구현**이므로, 1차 검토 시점의 이 모듈은 색등급도 작성과 시차 거리 비교까지였다는
  시점 구분을 넣었다.
- 표 4-6 의 CMD 산출값 칸을 «시차 기반 거리(구조 구현 및 시연용)» → «등시선 맞춤으로 얻은 나이·거리·성간소광,
  Gaia 시차 기반 거리»로 갱신.
- 참고문헌에 **Bressan et al. (2012)** 와 **Wang & Chen (2019)** 를 추가(54 → 56편).
