## 채운 것 넷

### 1. 3.5 자료 제품·분석 방법 명세에 성단 색등급도가 아예 없었다

절 제목이 「식현상 모듈의 자료 제품과 분석 방법 명세」였고, 미시중력렌즈는 모델 한 줄만, 성단은 **0회**였다.
절 제목을 「세 탐구모듈의…」로 바꾸고 두 모듈의 명세를 코드에서 확인해 채웠다.

**미시중력렌즈 — 새로 적은 것**

| 항목 | 내용 (`kmtnet_lightcurve_service.py`) |
|---|---|
| 자료 제품 | KMTNet 공개 아카이브의 관측소별 측광 결과 테이블(`.pysis`) |
| 관측소 | 칠레 CTIO · 남아공 SAAO · 오스트레일리아 SSO, I 밴드 |
| 읽는 열 | 시각(HJD), 등급, 등급 오차 |
| 전처리 | 등급 오차 0.3 초과 제외 → 관측소별 영점 정렬 → 병합 |
| 학습자가 실행 | 병합 + 모델 적합. **영상 측광은 수행하지 않음** |

**성단 색등급도 — 새로 적은 것**

| 항목 | 내용 (`cluster_service.py`, `parsecGaiaIsochrones.json`) |
|---|---|
| 자료 제품 | ESA Gaia DR3 `gaiadr3.gaia_source`, Gaia TAP 질의 |
| 대상 | 산개성단 **12개**, 성단별 검색 반경 0.5°~2° |
| 선별 조건 | 시차 창 + 고유운동 창(성단별) + **RUWE < 1.4** + 색지수·등급 결측 제외, 최대 3,000개 |
| 조건의 성격 | 시차·고유운동 창은 **카탈로그 값이 아니라 앱의 작업용 조건**이며 학습자가 못 만짐 |
| 등시선 | PARSEC v1.2S(CMD 3.8), Gaia EDR3 측광계, Kroupa 초기질량함수 |
| 조절 가능 | 나이(log 6.6~9.9), 거리지수, A_V, **금속함량 4단계**([M/H] −0.5·−0.25·0·+0.25) |
| 소광 계수 | A_G/A_V = 0.806, E(BP−RP)/A_V = 0.429 (Wang & Chen, 2019) |
| 기준값 | Cantat-Gaudin et al. (2020) 표 1의 거리·log(나이)·A_V, 2026-09 재조회 |
| 모델에서 뺀 것 | 쌍성, 항성 자전. 네 조절값이 서로 보상된다는 안내를 화면에 표시 |

참고문헌에 **Cantat-Gaudin et al. (2020)** 추가(56 → 57편).

### 2. 표 4-4에 Gaia DR3 열이 없었다

본문은 «MAST 기반 TESS, KMTNet, ESA Gaia DR3, NASA Exoplanet Archive를 선정하였다»고 쓰는데, 표에는
**TESS·KMTNet·기준값 세 열뿐이었다.** 제목도 「외계행성 탐사 탐구를 위한…」이라 성단이 들어갈 자리가
없었다. 제목을 「탐구모듈별 공공 천문자료 선정 결과」로 바꾸고 Gaia DR3 열을 여섯 기준 모두에 채웠다.

### 3. 3.5에 이중 언어와 계정 기반 기능이 없었다

| 웹에 있는 것 | 종전 원고 |
|---|---|
| 한국어·영어 두 언어, 화면에서 전환(기본 한국어, 문구 797곳) | **0회** |
| 로그인 후 분석 저장·다시 열기·측광 결과 표 파일 내려받기·링크 공유 | **0회** |

이중 언어는 사례분석이 지목한 영어 인터페이스 부담과 직접 연결되는 설계 결정이라 적어야 한다.
계정 기능은 **두 조사 모두 로그인 없이 진행했으므로 검토 대상이 아니라는 점**을 함께 밝혔다.

### 4. 화면 그림이 식현상 모듈만인 이유를 밝히지 않았다

그림 4-5~4-8이 모두 식현상 화면이다. 「검토와 산출값 비교의 대상인 식현상 모듈만 제시하였으며, 나머지
두 모듈의 화면 구성은 표 4-6에서 항목별로 비교하였다」는 한 문장을 넣었다.
