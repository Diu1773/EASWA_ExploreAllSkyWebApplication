# EASWA 프로토타입 반응조사 — 배포 · 논문 패키지

교사 연수 **현장 대면 사용**과 **온라인 배포**(다양한 배경의 응답 수집)를 모두 지원하는
설문 패키지입니다. 대상 모듈은 **외계행성 식현상(transit)**, 형식은 구글폼(이미지·웹링크 제시형),
익명·단일 폼. 논문 `2026_Cosmos_ERP` **§3.6(조사 방법)·§4.5(조사 결과)**와 1:1 정합됩니다.

## 2. 구글폼 만들기 (약 5분)

1. `script.google.com` → **새 프로젝트** → `easwa_teacher_survey.gs` 내용 붙여넣기
2. `createEASWAForm` 실행 → 권한 승인
3. 실행 로그(보기 → 로그)에서 **편집 URL / 응답 URL** 확보
4. **화면 이미지 삽입** — 폼 편집기에서 `3. EASWA 프로토타입 화면 확인` 섹션의 각 "화면 N" 설명 아래에
   아래 매핑대로 이미지 추가(이미지 삽입 → 업로드):

   | 폼의 화면 | 넣을 파일 |
   |---|---|
   | 화면 1 | `step0_intro.png` (+ `step1_select.png`) |
   | 화면 2 | `step2_metadata.png` |
   | 화면 3 | `step3_conditions.png` |
   | 화면 4 | `step4_analysis.png` |
   | 화면 5 | `step5_reference.png` |
   | 화면 6 | `step6_record.png` |

   > 자동화 원하면: PNG들을 Google Drive에 업로드 → 파일 ID 확보 → `.gs`의 해당 `addInfo(...)`를
   > `addImg('화면 N. …', '설명', 'DRIVE_FILE_ID')`로 교체 (헬퍼는 `.gs` 하단 주석 참조).

5. **폼 QR 생성**: 응답 URL로 아래 실행
   ```bash
   python make_qr.py "<응답_URL>" qr_form.png "설문 응답"
   ```

## 3. 배포 설정 (온라인·현장 공통)

폼 편집기 → 설정(⚙️):
- **응답 → 이메일 주소 수집: 사용 안 함** (익명 보장, `.gs`에서 이미 `setCollectEmail(false)`)
- **응답 → 로그인 필요/1인 1응답: 끔** (링크 있는 누구나 응답 → 폭넓은 수집)
- **게시 → 링크가 있는 모든 사용자**에게 응답 허용
- 진행률 표시줄: 켬(`.gs` 기본값)

## 4. 두 가지 사용 맥락

### (A) 교사 연수 현장 (대면 시연 + 즉석 응답)
1. 스크린에 **웹앱 QR**(`qr_easwa_webapp.png`) 띄우기 → 교사들이 직접 앱 접속·조작
2. 식현상 모듈 Step 0~6 시연 (원하면 WASP-6 b로 실제 분석까지)
3. 시연 후 **폼 QR** 배포 → 즉석 응답
4. 앱을 못 연 참여자도 **폼에 삽입된 화면 이미지**로 응답 가능

### (B) 온라인 배포 (다양한 배경의 응답)
1. **폼 링크/QR**을 지구과학 교사 커뮤니티·SNS·메일 등으로 공유
2. 폼에 화면 이미지가 들어 있어 **앱 없이도 자립적 응답** 가능 (웹 링크는 선택)
3. **Q7(확인 방식)**으로 "웹 직접 사용 / 이미지만 / 둘 다"를 구분 →
   실제 상호작용 경험에 의존하는 문항(가시화·해석 등)은 확인 방식과 연결해 **제한적으로 해석**
   (논문 §3.6 해석 유의사항과 직접 연결)

## 5. 논문 정합 (이미 1:1 일치 — 본문 수정 불필요)

| 논문 표 | 폼 대응 | 상태 |
|---|---|---|
| 표 3-4 (조사 구성) | 7개 섹션(배경·장벽·확인방식·반응척도·어려운단계·보완요구·자유의견) | ✅ |
| 표 3-5 (반응척도 7문항) | Q8~14 (탐구주제중심·기술부담완화·가시화·STEP스캐폴딩·결과해석·수업적용·종합) | ✅ |
| 표 4-8 (활용 장벽 8) | Q5 | ✅ |
| 표 4-10 (어려운 단계 6) | Q15 | ✅ |
| 표 4-10 (보완 요소 7) | Q17 | ✅ |

- **§3.6(방법)은 이 폼을 정확히 기술 중** → 그대로 사용.
- **§4.5(결과)**의 표 4-7~4-11은 `[자료 수집 후 작성]` placeholder → **응답 수집 후 숫자만 채우면 완성**.
- 리커트: 평균·표준편차 + **응답 빈도 분포 병기**(소표본 편향 완화, §3.6 유의사항).
- 자유응답: 연역 범주(장벽·접근부담·가시화·해석지원·STEP안내·수업적용) 중심 + 신규 범주 추가.

### §3.6에 추가 권장 문장 (배포 맥락 반영, paste-ready)
> 본 조사는 교사 연수에서의 대면 시연과 온라인 구글폼 배포를 병행하여, 현직 및 예비 지구과학교사와
