교사 연수 **현장 대면 사용**과 **온라인 배포**(다양한 배경의 응답 수집)를 모두 지원하는
설문 패키지입니다. 대상 모듈은 **외계행성 식현상(transit)**, 형식은 구글폼(이미지·웹링크 제시형),
익명·단일 폼. 논문 `2026_Cosmos_ERP` **§3.6(조사 방법)·§4.5(조사 결과)**와 1:1 정합됩니다.

## 2. 구글폼 만들기 (약 5분)

1. `script.google.com` → **새 프로젝트** → `easwa_teacher_survey.gs` 내용 붙여넣기
2. `createEASWAForm` 실행 → **권한 승인**(폼 생성 + 외부 이미지 접근 `UrlFetchApp` 권한 요청 → 허용)
3. **끝.** 문항 + **화면 1~6 이미지가 자동 삽입**됩니다.
   - 이미지는 GitHub raw(`docs/survey/screens/*.png`)에서 실행 시 자동으로 끌어옴 → 수동 업로드 불필요.
4. 실행 로그(보기 → 로그)에서 **편집 URL / 응답 URL** 확보
5. **폼 QR 생성**: 응답 URL로 아래 실행
   ```bash
   python make_qr.py "<응답_URL>" qr_form.png "설문 응답"
   ```

> 이미지 URL은 `.gs`의 `IMG_BASE`(브랜치 `block-ux-overhaul`)를 가리킵니다. 브랜치명이 바뀌면 `IMG_BASE`도 수정.

### 익명 결과 제출 수신부 배포 (약 3분)

1. 새 스프레드시트 → 확장 프로그램 → Apps Script → `easwa_record_sink.gs` 붙여넣기
2. 배포 → 웹 앱 (실행: 나 / 액세스: **모든 사용자**) → URL 확보
3. URL을 `frontend/.env`와 Render 환경변수의 `VITE_RECORD_SINK_URL`에 설정 → 재빌드/재배포 (미설정 시 버튼은 '제출 서버 미설정' 비활성 표시)

## 4. 두 가지 사용 맥락

### (A) 교사 연수 현장 (대면 시연 + 즉석 응답)
1. 스크린에 **웹앱 QR**(`qr_easwa_webapp.png`) 띄우기 → 교사들이 직접 앱 접속·조작
2. 식현상 모듈 Step 0~6 시연 (원하면 WASP-6 b로 실제 분석까지)
3. 시연 후 **폼 QR** 배포 → 즉석 응답
4. 앱을 못 연 참여자도 **폼에 삽입된 화면 이미지**로 응답 가능

### (B) 온라인 배포 (다양한 배경의 응답)
1. **폼 링크/QR**을 지구과학 교사 커뮤니티·SNS·메일 등으로 공유
2. 폼에 화면 이미지가 들어 있어 **앱 없이도 자립적 응답** 가능 (웹 링크는 선택)
3. **Q7(확인 방식, 5구분)**으로 "진행자 안내 직접 수행 / 스스로 직접 수행 / 일부 확인 / 이미지만 / 미확인"을 구분하고,
   **Q7-1(완료 수준)·Q7-2(수행 시간)**을 함께 수집 →
   실제 상호작용 경험에 의존하는 문항(가시화·해석 등)은 확인 방식 집단과 연결해 **제한적으로 해석**,
   온라인 응답은 **참고 자료**로 보고 (논문 §3.6 해석 유의사항과 직접 연결)
