# 용어 표기 표 — 한국어 문구 안의 영단어

> 작성 2026-08-09. 근거: `frontend/src` 한국어 문구 850개에서 영단어 추출
> (고유명사·기호 제외). 교사 장벽 **2위**(영어 인터페이스·전문 용어, 9명)와
> 서술 11번 *"BTJD·BJD·Rp/R\*·χ²_red·ROI 등 생소한 용어들이 갑자기 튀어나오는데"* 의 대응.
> 문체 규칙은 `KOREAN_COPY_RULES.md`, 배치는 `FEEDBACK_ZOVIZ_MAP.md` F2.

## 0. 실제 문제는 번역이 아니라 일관성이다

앱은 **이미 한국어 용어를 갖고 있는데 자리마다 다르게 쓴다.**

| 개념 | 한국어로 쓴 자리 | 영어로 쓴 자리 |
|---|---|---|
| aperture | `구경을 조절하려면 Step 1로 돌아가세요` | `예: aperture·ROI` · `sector, aperture, 비교성, ROI…` |
| transit | `식현상 모델 적합` | `transit fit` · `광도곡선 생성과 transit model fit` |
| residual | `잔차` | `residual` |
| outlier | `이상치` | `outlier` |
| CMD | `색-등급도(CMD)` ← **바람직한 형태** | `성단 CMD 탐구블럭` |

즉 새로 번역할 것은 적고, **이미 있는 한국어로 통일하고 첫 등장에 원어를 병기**하면 된다.

## 1. 표기 규칙

0. **모르는 말은 툴팁으로 푼다** — 소유자 결정 2026-08-09: *"주연감광같은건 느낌표나
   툴팁 넣어서 부가설명 넣는 방식으로."* 라벨 옆에 작은 `ⓘ` 를 달고, 짚으면 한 줄 설명이
   뜬다. **라벨 안에 풀어쓰지 않는다** — 라벨이 길어지고 표가 무너진다.
   적용 예: `docs/design_mockup/step5_comparison.html` 의 «주연감광 계수 ⓘ».
1. **첫 등장은 「한국어(영문)」** — `색-등급도(CMD)`. 앱이 이미 쓰는 형태다.
2. **그 다음부터는 한국어만.** 같은 화면에서 반복하지 않는다.
3. **고유명사·미션명은 그대로** — TESS · NASA · Gaia · MAST · SIMBAD · VizieR · KMTNet · KASI.
4. **기호·단위는 그대로** — Rp/R\* · χ²_red · BJD · BTJD · ppm · px. 다만 **처음 나올 때
   한 줄 풀이**를 붙인다(용어 칩, F2).
5. 화면 라벨에는 **없는 말을 만들지 않는다.** `측광 구경` 은 이번에 내가 지어낸 말이고
   `구경` 이 맞다 — 소유자 지적 2026-08-09.

## 2. 확정 (소유자 2026-08-09)

| 영문 | 한국어 | 비고 |
|---|---|---|
| aperture | **구경** | 앱이 이미 쓰는 말. `측광 구경`·`구경 측광` 아님 |
| ROI | **관심영역**(ROI) | 소유자도 확신은 아님 — 첫 등장 병기로 두고 실사용에서 재검토 |
| sector | **섹터**(sector) | 음역하되 **무슨 뜻인지 한 줄 설명 필수** — TESS 가 하늘을 나눠 관측하는 구역 |
| cutout | **컷아웃**(cutout) | 번역이 애매해 음역. 한 줄 설명으로 보완 |
| blending | **혼합** | |
| contamination | **오염** | |
| CMD | **색등급도**(CMD) | 앱의 `색-등급도` 와 붙임표 통일 필요 |
| flux | **밝기** | 소유자: *"플럭스는 밝기잖아"*. 화면 라벨 `원시 Flux`·`배경 Flux` → `원시 밝기`·`배경 밝기` |
| stamp | 툴팁 | 소유자 결정 — 음역하고 `ⓘ` 로 뜻을 붙인다. cutout 과 개념이 겹치므로 설명에서 구분할 것 |
| overlay | 툴팁 | 〃 |
| cadence | 툴팁 | 〃 |

## 4-1. 별도 항목 — 앱의 1인칭

앱이 학습자에게 말하는 자리에 `내 측정` 처럼 **1인칭이 들어가 있다**
(`TransitComparison.tsx` 비교표 열 이름). 소유자 지적 2026-08-09 — *"내가 측정한 값?
말이 이상하게 들리잖아. 내가 누구야 여기서."* 화면 문구에서 «내/내가» 를 걷어내고
`측정값`·`직접 설정`·`직접 선택` 처럼 쓴다. 문체 규칙 ⑫.
