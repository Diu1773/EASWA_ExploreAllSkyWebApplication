## 이미지 위 설명문

**화면 1. EASWA 메인 화면**  
EASWA는 공공 천문자료를 활용하여 천문탐구를 수행할 수 있도록 구성한 웹 기반 탐구 플랫폼입니다.

**화면 2. 탐구 주제 및 분석 대상 선택 화면**  
사용자는 탐구 주제를 선택하고, 지도 화면에서 분석 대상 천체를 확인한 뒤 외계행성 식현상 탐구로 이동할 수 있습니다.

**화면 3. 외계행성 식현상 탐구 도입 화면**  
이 화면에서는 대표 탐구 질문을 제시하고, 학습 수준에 따라 안내형 탐구 또는 심화형 탐구 흐름을 선택할 수 있습니다.

**화면 4. Step 1 - 목표별·비교별 선택 화면**  
이 단계에서는 목표별과 비교별을 확인하고, aperture 조건을 조절하여 차등측광 분석에 사용할 자료 조건을 설정합니다. 화면에는 별 선택 패널, aperture 조절 영역, 관측 이미지, STEP별 생각해보기 질문이 함께 제시됩니다.

**화면 5. Step 5 - 식현상 모델 적합 결과 화면**  
이 단계에서는 광도곡선과 transit model fitting 결과를 확인하고, Rp/R*, a/R*, 궤도 경사각, 적합도 지표 등을 해석합니다.

**화면 6. Step 6 - 기준값 비교 및 결과 기록 화면**  
이 단계에서는 플랫폼 산출값을 NASA Exoplanet Archive 기준값 또는 문헌값과 비교하고, 차이가 발생한 원인을 자료 품질, 분석 조건, 모델 가정 등을 근거로 기록합니다.

## 설문 제외 화면

- `00_survey_contact_sheet.png`: 전체 흐름 확인용 합성본이다. 글자가 작으므로 설문에 사용하지 않는다.
- `05_step3_comparison_qc.png`: 비교별 품질 점검을 설명하는 논문 또는 부록용 화면이다.
- 상위 폴더의 나머지 기존 이미지: 최초 캡처본 및 논문 편집 참고용이다.

Google Form에서는 각 이미지 위에 화면 번호와 한 줄 설명을 넣는다. Step 번호와 Next 버튼은 이미지 안에서 모두 보여주려 하지 않고 설문 설명 문구로 안내한다.
