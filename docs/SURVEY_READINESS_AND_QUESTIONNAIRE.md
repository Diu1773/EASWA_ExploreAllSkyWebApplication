# EASWA 프로토타입 반응 조사 패키지

## 1. 설문 실시 가능 기준

현재 프로토타입은 다음 여섯 기준을 화면으로 제시한다.

| 설계 원리 | 사이트의 증거 | 설문용 화면 |
| --- | --- | --- |
| 탐구 주제 중심 접근 | 진입 화면에서 외계행성 식현상 모듈과 대표 탐구 질문을 제시함 | 화면 1, 2 |
| 기술 실행 부담 완화 | 코딩 없이 대상 선택, 자료 호출, 차등측광, 품질 점검, 모델 적합을 실행함 | 화면 3, 4 |
| 분석 과정의 가시화 | 자료 출처, 대상·Sector 정보, 비교성 수, ROI, 적합 조건, 품질 지표를 제시함 | 화면 3~7 |
| STEP별 스캐폴딩 | STEP 1~6에 O/X, 선택형, 서술형 질문과 확인 안내를 제시함 | 화면 4~8 |
| 결과 해석의 학습자 수행 | 측정값과 NASA 기준값을 비교하고 차이 원인을 직접 기록하게 함 | 화면 7, 8 |
| 수업 적용 가능성 지원 | 안내형 탐구, 권장 시간, 결과물, 단계별 질문과 최종 기록 양식을 제공함 | 화면 1, 4~8 |

판정 기준은 여섯 항목이 모두 화면에서 확인되고, 아래 운영 점검을 통과하는 것이다.

## 4. 설문 문항

### A. 기존 공공 천문자료 서비스 활용 장벽

| 번호 | 문항 |
| --- | --- |
| A1 | 기존 천문자료 서비스에서는 탐구에 적합한 대상과 자료를 찾기 어렵다. |
| A2 | 자료 검색, 다운로드, 파일 처리 과정은 학교 수업에서 활용하기에 부담이 크다. |
| A3 | 코딩이나 전문 분석 도구 사용 요구는 학생 탐구의 장벽이 된다. |
| A4 | 자동 산출값만 제시될 경우 분석 과정과 결과의 신뢰도를 판단하기 어렵다. |
| A5 | 공공 천문자료를 수업에 활용하려면 교사가 별도의 활동지와 안내 자료를 많이 준비해야 한다. |

### C. STEP별 질문과 퀴즈의 적절성

각 단계에 대해 동일한 5점 척도로 응답한다.

| 번호 | 단계 | 문항 |
| --- | --- | --- |
| C1 | STEP 1 비교성 선택 | 질문이 비교성 선택 기준을 이해하는 데 적절하다. |
| C2 | STEP 2 차등측광 실행 | 질문이 구경과 비교성 수가 측정에 미치는 영향을 생각하게 한다. |
| C3 | STEP 3 비교성 품질 점검 | 질문이 RMS와 비교성 제외 근거를 판단하는 데 적절하다. |
| C4 | STEP 4 광도곡선과 ROI | 질문이 식 깊이와 식 구간을 해석하는 데 적절하다. |
| C5 | STEP 5 Transit fit | 질문이 `Rp/R*`와 적합도 지표를 해석하는 데 적절하다. |
| C6 | STEP 6 결과 기록 | 질문이 기준값 차이와 오차 원인을 설명하는 데 적절하다. |

### D. 어려울 것으로 예상되는 단계

복수 선택, 최대 2개:

- STEP 1 목표 별과 비교성 선택
- STEP 2 구경 설정과 차등측광 실행
- STEP 3 비교성 품질 판단
- STEP 4 광도곡선에서 식 구간 선택
- STEP 5 Transit fit 조건과 산출값 해석
- STEP 6 기준값 비교와 최종 설명 작성
- 특별히 어려운 단계가 없을 것 같음

선택 이유:

> 해당 단계가 어렵다고 예상한 이유를 간단히 적어 주십시오.

### E. 보완 요구 우선순위

가장 필요한 항목 3개를 선택:

- 용어 설명 강화
- STEP별 예시 답안 또는 해석 예시
- 분석 조건 추천값 설명
- 오류 발생 시 해결 안내
- 그래프 읽기 안내
- 기준값과 측정값 차이 설명 자료
- 학생용 활동지
- 교사용 지도안과 수업 운영 자료
- 수업 시간에 맞춘 축약형 활동
- 심화 탐구 기능
- 모바일 화면 개선

## 5. 응답 분석 기준

- A 영역: 기존 서비스 활용 장벽의 평균과 문항별 응답 분포
- B 영역: 설계 원리별 3개 문항 평균과 표준편차
- C 영역: STEP별 질문 적절성 평균과 가장 낮은 단계 확인
- D 영역: 어려운 단계 선택 빈도와 이유 범주화
- E 영역: 보완 요구 선택 빈도와 우선순위
- F 영역: 접근성, 기술 부담, 과정 이해, 결과 해석, 수업 적용 범주로 코딩

B 영역은 설계 원리별로 묶어 제시하고, 전체 만족도 점수로만 합산하지 않는다.
