## 제목은 명사구, 요지는 그 아래 한 줄 — 스킬을 그대로 따르지 않았다

스킬이 요구하는 **action title**(요지를 담은 완결 문장)은 영어 관습이다. 그대로 옮겼더니
사장님이 **「AI 티 나는 게 제목절이 영어번역체임」**이라 하셨다. 열두 제목 중 일곱이
「A하지만, B했다」꼴, 둘이 「A가 아니라 B」 부정 대구였다.

한 절로 줄여 봤으나 **「그래도 별로」**였다. 짧게 만들어도 **완결 서술문이라는 게
그대로**였기 때문이다. 「탐구보다 자료 준비가 먼저 온다」는 신문 표제지 발표 제목이
아니고, 「교사 26명이 짚은 것은 해석이었다」는 영어 분열문(It-cleft) 냄새가 난다.

**사장님이 고른 답 — 명사구 제목 + 그 아래 한 줄 요지.** 한국 학회 관례를 지키면서,
「제목만 훑어도 논지가 이어진다」는 스킬의 목적은 요지 줄이 대신 맡는다.

| 제목 (명사구) | 요지 (한 줄) |
|---|---|
| 연구 배경 | 자료는 공개되어 있지만 수업에서 쓰려면 준비 절차가 앞선다 |
| 기존 서비스 분석 | 네 서비스 모두 탐구 흐름은 사용자 몫이었다 |
| EASWA의 구조 | 자료가 다른 세 모듈에 같은 일곱 단계를 적용하였다 |
| 웹 기능 ① 탐구 질문 진입 | 천체명·좌표가 아닌 질문에서 대상과 자료로 이어진다 |
| 웹 기능 ② 분석 조건 설정 | 구경·배경·비교성을 학습자가 정한다 |
| 웹 기능 ③ 기준값 비교와 기록 | 산출값을 카탈로그 값과 나란히 두고 해석을 남긴다 |
| 개발 방식과 검증 | AI가 쓴 코드는 실행되어도 값이 틀릴 수 있다 |
| WASP-121 b 처리 조건별 결과 | -12.8%가 -2.8%까지 좁혀졌다 |
| 점검의 한계 | 남은 -2.8%와 비교성의 효과는 나누지 못했다 |
| 사용자 검토 결과 | 실행 부담은 낮고 기준값 해석이 최하위였다 |
| 보완 요구 | 용어·그래프 해석과 수업용 자료에 몰렸다 |
| 결론 | 조건을 드러내야 차이를 설명하는 활동이 성립한다 |

본문에서도 「~것과 ~것은」 명사화 여섯 곳을 고쳤다.

## 문체는 개조식이다

사장님 지시 — *「~다 말고, 음, ~했음 않음 이 말투로」*. 한국 발표자료·보고서의
표준 문체다. **서술어를 명사형 어미(-(으)ㅁ)로 닫고, 두 절은 마침표나 줄표로 끊는다.**
요지 줄과 본문 마흔네 곳을 바꿨다(`to_gaejo.py`).

| 전 | 후 |
|---|---|
| 자료는 이미 충분하다. | 자료는 이미 충분함 |
| 네 곳 모두 … 두지 않았다. | 네 곳 모두 … 서비스 밖에 있음 |
| 설치도 로그인도 없다. 브라우저에서 바로 열린다. | 설치·로그인 없이 브라우저에서 바로 열림 |
| 화면이 돌아간다고 값을 믿을 수는 없다. | 화면이 돌아간다고 값을 믿을 수 없음 |
| 실행을 돕는 일과 해석을 돕는 일은 다른 과제다. | … 다른 과제임 |

**본문을 고칠 때 이 문체를 깨지 않는다.** `build.py` 안에서 「~다」로 끝나는 문장이
보이면 주석이나 파일 머리글이지 슬라이드 글이 아니다.

## 기존 웹 환경은 두 장이다 — 갈래마다 화면 둘

다섯 판을 거쳤다.

1. 자료 제공 서비스 넷만 → *「교육용 웹들도 있는데 왜 없냐, 안 찾아봤냐」는 질문이
   들어올 가능성이 있음*
2. 부록에 목록을 붙임 → *「부록2에 붙일게 아니라;; 기존서비스들, 웹 새로만들어서 넣어야지」*
3. 한 장에 두 칸 글 목록 → *「차라리 simbad 교육지향에 하나, 넣고 사진을 크게」*
4. 한 장에 화면 둘(SIMBAD · Agent Exoplanet 첫 화면) → *「뭔가 교육적인걸 하는 화면을
   담고싶은데」*
5. **지금 — 갈래마다 한 장씩, 화면 둘씩**
   *「기존 웹 환경 예시1, 2 이렇게 두고 1에는 simbad vizier, 2에는 저 성단그림이랑,
   hunters 사진 두개 크게 좀 넣고 설명 간단히」*

| | 왼쪽 | 오른쪽 |
|---|---|---|
| **예시 ① 자료 제공 서비스** | SIMBAD | VizieR |
| **예시 ② 교육 지향 환경** | SDSS Voyages 성단 색등급도 활동 | Planet Hunters TESS 분류 |

예시 ② 아래에 **EASWA 의 자리**를 한 줄로 둔다. **「최초」라고 쓰지 않는다.**

**교육 지향 환경 둘을 고른 이유**

- **SDSS Voyages 성단 활동** — EASWA 의 Gaia 성단 색등급도 모듈과 **같은 주제**다.
  안내문에 「자료를 그리려면 Excel 이나 Google Sheets 가 필요하다」고 **그쪽이 적어 두었다.**
- **Planet Hunters TESS** — 실제 TESS 자료를 대중이 만지는데 과업이 **분류**다.
  이미 만들어진 광도곡선에서 식현상을 눈으로 표시할 뿐, 대상 선택도 측광도 모델 적합도 없다.

## 팝업이 덮는 화면은 `shoot.py` 로 찍는다

Chrome 의 `--screenshot` 은 클릭을 못 한다. Planet Hunters 는 첫 방문마다 튜토리얼 팝업이
뜨고 그 상태가 localStorage 에 남지 않아 헤드리스로는 늘 덮인다. 창을 키우거나 프로필을
데워도 안 된다. **DevTools 프로토콜로 붙어 팝업을 DOM 에서 걷어낸 뒤 찍는다.**

```
python -X utf8 docs/발표_추계2026/shoot.py <url> <out.png> [w] [h] [지울 선택자]
```

`--remote-allow-origins=*` 가 없으면 웹소켓 악수가 403 으로 막힌다.
