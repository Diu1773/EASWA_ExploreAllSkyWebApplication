## 사실이 틀린 것 — 먼저 볼 것

### S-1. 우상향하는 곡선을 「평평해요」라고 말한다 (캡처 2)

**현재** `TransitLab.tsx:3136-3140`

```
안정적 — "다른 별들과 나란히 평평해요. 좋은 기준별입니다."
보통   — "대체로 평평해요. 함께 써도 됩니다."
불안정 — "혼자 출렁여요. 이 별은 빼는 게 좋겠습니다."
```

**원인**(`TransitLab.tsx:1209-1214`)

```ts
const qcRmsTier = (rms) => {
  const worseThan = qcRmsSorted.filter((v) => v < rms).length;
  const rank = worseThan / (qcRmsSorted.length - 1);   // 0 = 가장 평평, 1 = 가장 시끄러움
  return rank <= 0.34 ? 'steady' : rank <= 0.67 ? 'typical' : 'noisy';
};
```

판정이 **순위만 본다.** 비교성 8개 중 하위 34%에 들면 무조건 「안정적」이다. 전부 나빠도 그중 제일
나은 것이 「안정적」이 된다. 게다가 쓰는 값이 `differential_rms`, 곧 **산포**뿐이라 **기울기를 못 잡는다.**
캡처 2의 곡선은 0.996에서 1.006까지 한쪽으로 올라가는데 점이 촘촘해 RMS는 0.0023으로 작다.
그래서 「평평해요」가 뜬다. 문장이 자료와 어긋난다.

**제안** — 두 가지를 함께 고친다.

1. **추세를 같이 잰다.** 시간에 대한 1차 기울기를 구해 전체 구간에서 밝기가 몇 % 변했는지 본다.
   산포(RMS)와 추세(기울기)는 다른 결함이므로 따로 표시한다.
2. **순위 대신 절대 기준을 앞세운다.** 순위는 「이 별들 중에서는」이라는 뜻이므로, 문구도
   그렇게만 말한다.

| | 지금 | 바꿀 안 |
|---|---|---|
| 안정적 | 다른 별들과 나란히 평평해요. 좋은 기준별입니다. | 흔들림이 이 중에서 작은 편입니다. |
| 보통 | 대체로 평평해요. 함께 써도 됩니다. | 흔들림이 중간입니다. |
| 불안정 | 혼자 출렁여요. 이 별은 빼는 게 좋겠습니다. | 흔들림이 이 중에서 큰 편입니다. |
| (신설) | — | 기울기가 크면 「관측 기간 동안 밝기가 ○○% 한쪽으로 변했습니다」를 함께 띄운다 |

**판단 필요**: 기울기 계산을 넣으면 백엔드 `differential_rms` 옆에 값을 하나 더 내려야 한다.
시연 전에 하기에는 손이 큰 편이다. **문구만 먼저 고치고 기울기는 시연 뒤**로 나눌 수 있다.
