EASWA 소개

연구용으로 공개된 천문 관측자료를 학교 수업에서 쓸 수 있게 만든 웹입니다.

실제 관측자료

연습용으로 만든 자료가 아니라 관측소가 공개한 자료를 그대로 불러옵니다.

자동 분석

자료 내려받기와 전처리, 측광, 모델 적합을 웹에서 자동으로 수행합니다.

분석 과정 공개

자동으로 계산하되 어떤 설정과 모델 가정을 썼는지 화면에 함께 표시합니다.

기준값 비교와 기록

측정값과 문헌 기준값을 같은 화면에 놓습니다. 차이의 원인은 학생이 직접 적습니다.

교사용 안내

학생이 어떤 자료와 조건으로 그렇게 판단했는지 확인할 수 있습니다.

차시 배분한 모듈에 40~80분이 걸립니다. 짧은 모듈은 한 차시에 두 개를 배치할 수 있습니다.
모둠 편성계산이 자동이므로 모둠별로 분석 조건을 다르게 설정해 결과를 비교할 수 있습니다.
난이도 조절입문 과정과 심화 과정으로 나뉩니다. 측정의 불확실성과 한계는 각 단계에서 함께 다룹니다.
