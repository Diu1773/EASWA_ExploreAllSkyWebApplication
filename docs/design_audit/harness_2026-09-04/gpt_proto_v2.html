01 / TESS

외계행성 식현상

TESS 공개 관측자료에서 밝기 감소를 측정하고 차등측광·식현상 모델 적합을 거쳐 NASA Exoplanet Archive 기준값과 비교합니다.

DATANASA TESS / MAST
ANALYSIS차등측광 · Transit fit
COMPARENASA Exoplanet Archive
CLASS45–90분 · 고등학교 심화 / 대학 교양
외계행성 탐구 시작 현재 구현
PROVENANCENASA · STScI MAST
OUTPUTLight curve · Rp/R* · depth
02 / GAIA

성단 색-등급도(CMD)

Gaia DR3 측광자료에서 성단 구성원을 선별하고 색-등급도를 그려 주계열·전향점·거리 단서를 해석합니다.

DATAESA Gaia DR3
ANALYSIS구성원 선별 · BP−RP / G CMD
COMPARE등시선 또는 문헌 CMD
CLASS45분 · 중등 심화~고등
성단 CMD 탐구 시작 현재 구현
NASA/ESA/AURA·Caltech
PROVENANCEESA Gaia · gaiadr3.gaia_source
OUTPUTCMD · turn-off · distance clue
03 / KMT

KMTNet 미시중력렌즈

CTIO·SAAO·SSO의 다지점 광도곡선을 결합해 미시중력렌즈 증광을 확인하고, 단일렌즈 곡선에서 벗어나는 짧은 아노말리를 탐색합니다.

DATAKASI KMTNet
ANALYSIS차분측광 · Paczyński fit · anomaly 확인
SITESCTIO · SAAO · SSO
STATUS실제 이벤트 adapter / 수업용 sample set 연결 준비
KMTNet 탐구 보기 데이터 연결 준비 중
NASA / KMTNet related visualization
NETWORKChile · South Africa · Australia
OUTPUTLight curve · t0 · u0 · tE · residual

RECORD판단과 근거를 기록으로 저장

수업에서 사용할 때

탐구 모듈은 분석 도구와 함께 학습 목표, 단계별 질문, 자기점검, 해석·기록 항목을 제공합니다. 교사는 계산 결과보다 학생이 자료와 분석 조건을 근거로 설명하는 과정을 확인할 수 있습니다.
