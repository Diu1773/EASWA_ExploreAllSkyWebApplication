## 반영한 판단

1. 제목은 설계 과정을 모두 나열하지 않고 연구의 산출물과 적용을 드러내도록 고쳤다. 국문 제목에는 교육용 웹 플랫폼과 EASWA의 전체 이름을 함께 적고, 영문에서는 `App` 대신 `Application`을 사용하였다.
2. 국문·영문 요약은 연구 결과를 항목별로 나열하던 방식에서 개발 순서, 적용 범위, 참여자 반응, 교육용 웹 플랫폼에 대한 제언이 이어지도록 다시 구성하였다. 산출값 점검과 교사 대상 적용은 외계행성 식현상 탐구활동에서만 했다는 범위를 유지하였다.
3. 주제어는 검색 가능성을 고려하여 `공공 천문자료, 천문교육, 과학탐구, 교육용 웹 플랫폼, 외계행성 식현상`으로 정리하였다.
4. Ⅱ장은 저자 이름으로 문장을 시작하지 않고 개념과 연구상 필요를 먼저 설명한 뒤 근거 문헌을 붙이는 방식으로 고쳤다. 출처가 필요한 정의·이론·선행 결과의 인용은 유지하였고, 앞선 문헌을 천문 관측자료에 적용해 정리한 문장은 종합 문장임을 밝혔다.
5. Ⅲ장의 개발 순서는 `외계행성 식현상 시험 구현 → 이론·서비스·교육과정·교과서 검토 → 설계 원리와 공통 탐구 흐름 정리 → 세 주제별 탐구활동 구현 → 식현상 기능 점검 → 현직교사 적용·보완 → 예비교사 적용`으로 명시하였다. 사례분석은 초기 구현을 평가한 절차가 아니라 최종 원리를 정리할 때 학교 활용에 필요한 지원을 확인한 절차라고 구분하였다.
6. 논문 용어는 `탐구모듈` 대신 `주제별 탐구활동` 또는 `탐구활동`을 사용하였다. 첫 화면의 실제 UI 요소만 `탐구활동 선택 카드`로 불렀으며, 논문 개념으로 `탐구블록`이나 `카드블록`을 새로 만들지 않았다.
7. 장 구조는 Ⅳ장을 EASWA의 개발 결과와 기술 점검, Ⅴ장을 교사 대상 적용 결과 분석, Ⅵ장을 토의, Ⅶ장을 결론 및 제언으로 나누었다.
8. 설문 결과 그림은 항목 문장이 길고 낮은 빈도의 범주가 많아 본문 이해를 돕지 못한다고 판단하여 삭제하였다. 연구문제에 답하는 주요 수치와 반복 응답은 Ⅴ장 본문에 남기고, 실제 보완 내용을 정리한 표 5는 유지하였다.
9. 그림 2는 실제 개발 순서에 맞는 일곱 단계로 다시 만들고, 그림 4는 세 주제별 탐구활동의 공통 흐름과 서로 다른 자료·분석 구조를 함께 보이도록 용어와 구성을 고쳤다. 화면 그림의 긴 캡션은 줄이고 필요한 설명을 본문으로 옮겼다.
10. 국내 선행연구로 유창현(2025), 함경림·이종원(2009), 함경림 외(2024)를 보강하고, 본문 논지에 직접 필요하지 않거나 다른 문헌과 역할이 겹치는 영문 문헌을 정리하였다. 참고문헌은 국문 14편, 영문 35편, 총 49편이다.
11. 그림 1~7의 캡션은 그림을 식별하는 한 줄짜리 명사구로 통일하고, 초기 화면의 구성·자료 출처·패널별 단계·개념 시뮬레이션 여부는 3.1과 4.3 본문으로 옮겼다. 그림 2 뒤에 있던 연구문제별 자료 대응 문단은 절차를 되풀이하고 있어 삭제하였다. 표 5개의 제목 위와 표 아래에는 각각 6pt의 문단 간격을 적용하고, 국·영문 저자명 뒤의 교신저자 별표는 학회 템플릿과 같은 윗첨자로 바꾸었다.
