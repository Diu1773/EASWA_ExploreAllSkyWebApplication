# 최종 원고 반영 메모

원고 파일은 현재 저장소에 포함되어 있지 않으므로 최종 편집 시 아래 항목을 적용한다.

1. 용어 통일
   - `천문 공공데이터` → `공공 천문자료`
   - `공공데이터 기반 천문탐구` → `공공 천문자료 기반 천문탐구`
   - 표, 그림 설명, 장·절 제목, 본문에서 동일하게 적용

2. 1.5 제목 수정
   - 기존: `AI Agent 기반 프로토타입 개발과 구현 가능성`
   - 수정: `생성형 AI 기반 프로토타입 개발과 구현 가능성`

3. 결과 장 작성 시점
   - 4.4~4.7은 설문과 전문가 검토 자료 수집 전까지 `[자료 수집 후 작성]`으로 유지
   - 반응 조사 결과는 설계 원리별 문항 묶음으로 분석
   - 전문가 검토 결과는 설계 원리, 수정 요구, 반영 여부로 정리

4. 5장 논의
   - 설문 결과와 전문가 검토 결과가 확보된 뒤 재정리
   - 자동 분석 기능의 편의성보다 기술 부담 완화와 분석 과정 가시화의 균형을 중심으로 논의
   - 측정값·기준값 비교와 학습자 설명 활동이 결과 해석 원리를 어떻게 구현했는지 논의
