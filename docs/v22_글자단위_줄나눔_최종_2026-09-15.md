# v22 글자 단위 줄 나눔 최종 기록 (2026-09-15)

## 문제와 정정

`EASWA_논문_v22_투고본_최종.hwp`의 양쪽 정렬 본문에는 낱말 사이가 과도하게
벌어진 줄이 많았다. 처음에는 한글 COM의 `BreakNonLatinWord=1`을 글자 단위로
잘못 판정해 최종본에 적용했다고 보고했으나, 사용자가 실제 HWP 화면을 확인했을 때
간격은 그대로였다. 문제 문단을 직접 열어 보니 기존 최종본과 이른바 교정 후보가
모두 값 `1`이었고, 스크립트는 실제로 아무것도 바꾸지 않은 채 저장만 했다.

같은 파일을 A/B로 저장해 PDF를 렌더링한 결과는 반대였다. 이 문서와 한글 2022에서
`BreakNonLatinWord=0`을 적용해야 한글 어절 내부의 줄 나눔을 허용했고, 사용자가
지적한 「국내에서도 실제 천문자료와 데이터 사이언스를 활용한」 문단의 낱말 간격도
실제로 좁아졌다. 이 값을 HWPX로 내보내면 `breakNonLatinWord="BREAK_WORD"`로
기록된다. 종전 기록의 `1`·`KEEP_WORD` 매핑은 잘못이므로 사용하지 않는다.

## 반영 범위

- 표 밖 본문 전체와 표 200칸을 `BreakNonLatinWord=0`으로 고정하였다.
- `SelectAll`에서 빠진 교신저자 이메일 각주와 접수일 각주 두 문단도 같은 값으로
  바꾸었다.
- 부록 표 3 앞에 남은 예전 강제 쪽 나누기 한 개를 제거했으며, 이 과정에서 표 3
  캡션 첫 글자 run이 앞 문단 모양을 물려받지 않도록 `표제목` 스타일을 다시 적용했다.
- 공백 문자와 원고 내용은 바꾸지 않았다. 국문·영문 교신저자 별표와 이메일 각주도
  그대로 보존하였다.
