## 1. LLM 튜닝으로 옮겨 놓고 보면

| 기계학습 | 여기서는 |
|---|---|
| 학습 데이터 | 게재 논문 코퍼스 (분포를 정하는 쪽) |
| 검증 데이터 | 코퍼스에서 떼어 둔 논문 (역치를 시험하는 쪽) |

## 3. 지표 — 세 갈래로 나누고 근거를 붙인다

지금 열한 개는 근거 없이 모인 것이다. 갈래를 나누고 각각이 무엇을 재는지 적는다.

### (가) 분포형 — 게재 논문 분포와 견주는 것

| 지표 | 무엇을 재나 | 왜 |
|---|---|---|
| 평균 문장 길이 | 어절 | **근거를 아직 못 댔다.** 「짧게 끊는 것이 AI 특징」은 흔히 하는 말인데 국문 학술문에서 그렇다는 문헌을 찾지 못했다. 코퍼스로 직접 잰다 |
| 100자 넘는 문장 비율 | 천문장당 | 위와 짝. 길다고 나쁘지 않다 |
| 문장당 쉼표 | 개 | 열거 밀도 |
| 쉼표 구간 길이 | 어절 | 호흡 |
| 문두 접속사 | 천어절당 | 논리 연결자. 학술문은 원래 많다 |

### (나) 쏠림형 — 절 안 비율과 연속을 보는 것

| 지표 | 역치 후보 | 왜 |
|---|---|---|
| 같은 기능 종결 | 절의 65% 또는 5연속 | 낱말이 아니라 기능으로 묶는다 |
| 세 항 이상 나열 | 원고의 15% | 종결이 달라도 같은 박자로 들린다 |
| 문두 접속사 | 한 문단 3회 | |
| 「이는 ~」 | 한 문단 3회 | |

**분포형과 다르다.** 원고 전체 밀도가 아니라 **한 자리에 몰렸는지**를 본다.
게재 논문에도 총량은 있지만 몰리지는 않는다 — 이 가설을 코퍼스로 확인한다.

### (다) 꼴형 — 있으면 걸리는 것

| 지표 | 예 |
|---|---|
| 부정 대구 | 「A가 아니라 B다」 |
| 번역체 주어 | 개념이 주어 자리에 앉고 범용 동사로 끝남 |
| 마무리 꼴 | 「…을 보여준다」·「…와 연결된다」 |

**셋 다 게재 논문에서 얼마나 나오는지 먼저 잰다.** 12편에서 「~은 아니다」가
11편은 0이었는데, 300편에서도 그런지 봐야 진짜 신호다.

### 지표의 근거는 문헌이 아니라 이 코퍼스다

`research.py literature context` 로 공통 서고를 조회했다(2026-09-13, route AUDIT).
**서고 178건에 국문 학술 문체나 AI 생성 텍스트 탐지 문헌이 하나도 없다.** 매치 여덟은
전부 기상 예보·천문 관측 논문이라 무관하고, receipt 가 `external_search_required: true`
로 왔다.

외부 검색도 한 번 돌렸다(2026-09-13). 한국어 AI 생성 텍스트 탐지 연구는 있다 — KAIST 의
XDAC 가 ACL 2025 에 실렸고 F1 98.5% 를 보고한다. **그러나 대상이 뉴스 댓글이다.** 평균 51자,
구어체, 이모지가 섞인 짧은 글이다. 그 연구 자신이 「기존 탐지 기술 대부분이 영어로 된 장문의
정형화된 글을 기반으로 개발되어 한국어에 적용하기 어렵다」고 적는다.

**국문 학술 논문의 문체 기준선을 다룬 문헌은 찾지 못했다.** 검색 범위는 한국어 웹 한 회차이고,
KCI·DBpia 안쪽은 안 봤다. 더 있을 수 있다.

그러므로 **「AI는 문장을 짧게 끊는다」 같은 통설을 근거로 삼지 않는다.** 그것은 영어 장문
연구에서 온 말이고 국문 학술문에서 성립한다는 확인이 없다. 266편 게재 논문에서 실제 분포를
재고, 우리 원고가 그 분포의 어디에 놓이는지만 말한다. 문헌 근거가 필요한 자리에는
「근거 못 댐」이라고 적어 둔다.

> 출처: [alphaXiv 2403.01152](https://www.alphaxiv.org/ko/abs/2403.01152) ·
> [KAIST 연구뉴스](https://www.kaist.ac.kr/researchnews/html/news/?mode=V&mng_no=48130)

### 겹치는 지표는 하나만 남긴다

평균 문장 길이와 100자 넘는 문장 비율은 같은 것을 다르게 잰다. 상관계수를 재서
0.8 넘으면 하나를 뺀다. **지표가 많을수록 좋은 게 아니라, 서로 다른 것을 재야 좋다.**

## 4. 기준선 — 분포를 그대로 싣는다

지금은 최소·중앙·최대만 있다. 12편에서 최소와 최대는 표본 잡음이다.

**바꿀 것**: 사분위수와 5~95 백분위수를 싣는다. 역치는 **95 백분위수**로 잡는다.
정의상 정상 논문의 5%가 걸린다. 그것이 위양성률의 하한이다.

```json
{"평균 문장 길이": {"n": 287, "p5": 17.2, "q1": 21.4, "median": 24.6,
                    "q3": 28.1, "p95": 33.8, "min": 12.1, "max": 41.0}}
```

## 5. 검증 — 위양성률을 잰다

1. 코퍼스를 **8:2로 나눈다.** 80%로 분포를 만들고 20%는 손대지 않는다.
2. 그 20%에 검사기를 통째로 돌린다.
3. **지표마다 몇 편이 걸리는지 센다.** 이것이 위양성률이다.
4. 10%를 넘는 지표는 역치를 늦추거나 뺀다.
5. 남은 지표로 우리 원고를 잰다.

**이 절차를 거치지 않은 지표는 스킬에 넣지 않는다.**

덧붙여 **절 단위 검사도 같은 방법으로 시험한다.** 게재 논문의 방법 장을 뽑아
종결 쏠림을 재면, 「29문장 중 27개가 과거 보고」가 흔한 일인지 드문 일인지 나온다.
지금은 그걸 모르고 「심하다」고 말했다.

## 7-A. 코퍼스를 더 넓힐 수 있다 (2026-09-13 확인)

JAMS 를 쓰는 학술단체가 **1,606곳**이고 **모두 같은 API 를 쓴다.** 권호 목록은
`/sj/search/sjSereVolIsseClasList.kci`, 전체 내려받기는 `/co/download/popup/poDownLoadAll.kci`
이다. 학회 도메인만 바꾸면 같은 스크립트로 받아진다.

| 학회 | JAMS | 논문 수 |
|---|---|---|
| 한국과학교육학회 | `jkase` | 1,137 |
| 부산대 과학교육연구소 | `sciedu` | 807 |
| 서울대 한국현장과학교육학회 | `kosss` | 665 |
| 한국초등과학교육학회 | `keses` | 629 |
| 과학교육연구소 | `kseri` | 415 |

**국문 천문학 논문은 사실상 없다.** 한국천문학회의 학술지 천문학논총(PKAS)은 권호 86개가
Open Access 로 열려 있고 URL 도 `/journal/list.php?vol=NN&no=N` 로 단순한데,
**국문 제목이 0편이다.** 세 권호를 표본으로 확인했다(Vol.35·30·25). 국내 천문학자는
영문으로 쓴다.

그러므로 **「국문 천문 논문」은 과학교육 학술지에 실린 천문 주제 논문을 뜻한다.**
그것은 이미 코퍼스에 들어온다 — 현장과학교육에도 천체 관측·H-R도·외계행성 논문이 있다.
따로 모을 것이 아니라 **주제 태그로 갈라 보는 문제**다.

한국지구과학회는 JAMS 를 쓰지 않고 자체 사이트를 쓴다. 지구과학교육 논문이 필요하면
그쪽을 따로 뚫어야 한다.

**주의**: `kosss` 는 권호 목록을 서버에서 렌더하는데 `jkase`·`keses` 는 AJAX 로 채운다.
일반화하려면 HTML 파싱이 아니라 위 API 를 직접 불러야 한다.

| 「이는 ~」 | **0%** | 10.05 | **하나도 없다** |

### 두 가지를 다시 생각해야 한다

**하나. 과교정이 보인다.** 「이는 ~」이 266편 중앙값 10.05인데 우리는 0이다. 게재 논문
절반 이상이 쓰는 담화 장치를 「AI 티」로 보고 전부 지웠다. 문두 접속사 12%, 쉼표 구간
길이 7%도 같은 방향이다. **AI 티를 지우다 사람 글의 특징까지 지웠다.**

> 지표는 **양쪽 꼬리**를 봐야 한다. 지금 검사기는 「많으면 AI」만 본다.
> p5 아래도 신호다 — 사람 글에 흔한 것이 없는 것도 부자연스럽다.

**둘. 남은 신호는 부정 표현뿐이다.** 「~은 아니다」 96%와 부정 대구 88%가 유일하게
높다. 266편 중앙값이 둘 다 0.00 이므로 **대부분의 게재 논문은 이 꼴을 아예 안 쓴다.**
이건 12편일 때의 판정(11/12편이 0)과 같은 방향이고, 표본이 스물두 배가 되어도 유지됐다.

### 절 나누기는 정형어가 가장 낫다

계획 8절 4번 항목. 표본 12편으로 확인했다.

| 방법 | 세 번 이상 잡힌 편수 |
|---|---|
| 정형어(서론·연구방법·결론 …) | 10/12 |
| 아라비아 숫자 | 8/12 |
| 절 번호(1.1 꼴) | 4/12 |
| 로마 숫자 | 1/12 |

**정형어로 나누되 두 편은 실패한다.** 절 단위 검사를 코퍼스로 검증하려면 나뉜 편만
쓰고 몇 편을 못 나눴는지 함께 적어야 한다.

## 8. 열어 둔 것 — 토론에서 정할 것

1. **분야를 섞을까 나눌까.** 섞으면 분산이 커져 판정력이 떨어지고, 나누면 편수가
   준다. 현장과학교육만으로 300편이면 나누는 쪽이 가능해 보인다.
2. **2022년 경계가 맞나.** ChatGPT 공개는 2022-11-30 이지만 번역기와 문법 교정기는
   그 전부터 있었다. 2020년으로 당길지.
3. **위양성 10%가 맞나.** 더 좁히면 놓치는 게 늘고 늦추면 잡음이 는다.
4. **절 단위 검사의 분모.** 게재 논문 PDF 에서 절을 나눌 수 있나. 우리 원고는
   마크다운이라 절 제목이 명확한데 PDF 는 그렇지 않다.
5. **우리 원고를 PDF 로 재는 것이 맞나.** 지금은 조판본 PDF 에서 뽑는다. 같은
   잣대라는 장점이 있지만, 표와 캡션이 섞여 들어온다.
