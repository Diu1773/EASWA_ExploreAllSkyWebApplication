소유자가 Liner Scholar 로 v18 투고본을 검토시켰다. **5장 문체를 정확히 짚었다.**
우리 검사기는 5장을 「중앙 아래」로 통과시켰다. 왜 놓쳤는지 재고 정리한다.

## 2. 왜 우리 검사기가 5장을 놓쳤나

**구어체 문장이 전부 「기타」로 빠진다.** 종결이 「않는다·충실하다·온다·다르다·
떠안는다」라 네 묶음(과거 보고·현재 서술·당위·유보) 어디에도 안 걸린다.
세지 않으니 쏠림 계산에서 빠지고, 5장은 「중앙 아래」가 됐다.

### 장별 「기타」 비율 — 우리 잣대 밖 문장이 얼마나 되나

| 장 | 문장 | 기타 | 비율 |
|---|---|---|---|
| 요약 | 10 | 2 | 20.0% |
| **5장** | **86** | **17** | **19.8%** |
| 서론 | 54 | 10 | 18.5% |
| 결론 | 28 | 3 | 10.7% |
| 2장 | 39 | 4 | 10.3% |
| 4장 | 62 | 2 | 3.2% |
| 3장 | 72 | 2 | 2.8% |

## 2-A. **위 2절의 결론은 틀렸다** (같은 날 오후 확인)

2절에서 「기타 비율 자체가 신호다」라고 적었다. **아니었다.**

「떠안는다」와 「다룬다」를 검사기에 넣으면 **둘 다 「기타」**다. 현재형 종결 목록
(`NOW_TAIL`)에 없어서다. 목록을 넓히면 구어체도 함께 통과한다. 잡은 것은 구어체가 아니라
**「내 목록에 없는 낱말」**이었고, 5장에서 맞은 것은 우연이다.

구어체를 고친 뒤 같은 원고의 「기타」 84건을 갈라 보니 이랬다.

| 무엇 | 건수 | 기타의 |
|---|---|---|
| 캡션·제목·저자·소속·주제어·사사 | 64 | 76% |
| 목록 번호 (「1.」「2.」「3.」) | 3 | 4% |
| 물음 (연구문제 세 개) | 3 | 4% |
| 「않는다」류 | 5 | 6% |
| 현재형인데 목록에 없던 것 (다룬다·넓힌다·살펴본다·커진다) | 9 | 11% |
| **진짜 구어체** | **0** | **0%** |

1.3 의 「기타 50%」도 실은 「1.」「2.」「3.」 세 개와 물음표로 끝난 연구문제 셋이다.
**본문 문장은 하나도 안 걸렸다.**

### 그래서 무엇을 만들었나

`check_wording.py` — 원고의 용언이 게재 논문 267편 가운데 몇 편에 나오는지 센다.
사람이 「구어체 낱말 목록」을 짓지 않는다.

| 짚힌 것 | 잡나 | 뿌리 편수 |
|---|---|---|
| 떠안는다 | ○ | 0편 |
| 버티는지는 | ○ | 2편 |
| 충실하다 | ✕ | 「충실」 18편이라 흔한 말로 본다 |
| 서지 않는다 | ✕ | 「서지」는 명사(書誌)와 같은 꼴 |

**넷 가운데 둘이다.** Liner 를 대체하지 못한다. 다만 Liner 가 못 하는 것 — 267편 분포와
견주기 — 은 이쪽만 한다.

지금 원고에서 14자리를 짚었고 문안까지 냈다: `문안후보_2026-09-13.md`.

## 3. Liner 가 잡고 우리가 못 잡는 것

| 무엇 | 우리 검사기 | 있어야 할 것 |
|---|---|---|
| **오탈자** (바까지만) | 없다 | 맞춤법 검사. 가장 싸고 확실한데 없다 |
| **구어체 종결** (떠안는다·버티는지) | 「기타」로 버린다 | 기타 비율을 장별로 찍는다 |
| **원어 병기 필요** (교수과학) | 없다 | 사람 판정. 규칙화 어렵다 |
| **인용 부호 & / and 혼용** | 없다 | 표기 일관성 검사 |
| **한 문장이 세 문장 몫** (3.6) | 문장 길이로만 본다 | 절 하나에 서술 몫이 몇인지는 사람이 본다 |

## 4. 우리가 잡고 Liner 가 못 잡는 것

Liner 를 따라 만들자는 것이 아니다. **층이 다르다.**

| 무엇 | 우리 | Liner |
|---|---|---|
| 게재 논문 267편 분포와 견주기 | 있다 | 없다 |
| 못 하는 주장 (학습 효과·일반화) | 있다 | 없다 |
| 순환 논리 세 종류 | 있다 | 없다 |
| 장별 역할 (4장에 해석 금지) | 있다 | 없다 |
| 문체 교정 뒤 방어 진술 회귀 | 있다(손으로) | 없다 |
| 표·그림 고아·유령 참조 | 있다 | 없다 |
| 오탈자·맞춤법 | **없다** | 있다 |
| 문장별 인라인 교정안 | **없다** | 있다 (19건) |

**Liner 는 문장 층, 우리는 논증 층이다.** 둘 다 필요하고 겹치지 않는다.
