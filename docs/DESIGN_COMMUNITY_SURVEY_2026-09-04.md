# 커뮤니티·문헌 재조사 — 2026-09-04

`DESIGN_HARNESS_REVIEW_2026-09-04.md` 가 「GPT 하네스가 맞나」를 봤다면, 이 문서는
**같은 조사를 직접 다시 한 결과**다. 남의 요약을 믿지 않고 원자료를 열었고,
다른 커뮤니티에서 같은 조사를 한 번 더 돌려 재현되는지 봤고, 과학교육 쪽은
아예 다른 문헌군을 찾았다.

재현에 쓴 스크립트와 자료는 `docs/design_audit/community_2026-09-04/` 에 있다.

---

## 0. 세 줄 요약

1. **AI 티 조사는 원자료가 생각보다 튼튼하다.** 다만 GPT 요약이 **가장 중요한 항목을
   통째로 빠뜨렸다** — 2026년 1위 신호는 *안티-AI 조언을 따라 만들어진 새 기본값*이다.
2. **다른 커뮤니티(Hacker News)에서 981건으로 다시 세어 봤더니 상위 4개 순서가 그대로
   재현됐다.** 이 부분은 믿어도 된다. 대신 **언급 빈도를 가중치로 쓰면 안 되는 이유**도
   같이 드러났다.
3. **과학교육 축은 비교 대상 자체가 틀렸다.** GPT 하네스는 EASWA 를 전문가용 자료실
   (NASA Archive·SIMBAD·ESASky)과 비교했다. 비교해야 할 것은 **학습 환경 연구**이고,
   그 분야엔 EASWA 설계 원리와 거의 일대일로 맞는 표준 프레임이 이미 있다.

## 1. 축 1 — 원자료를 직접 열었다

### 1-1. 그 저장소는 링크 하나가 아니라 도구 한 벌이다

`github.com/JCarterJohnson/vibecoded-design-tells` 의 파일 목록을 받아 보니
README 만 있는 게 아니었다.

| 파일 | 내용 |
|---|---|
| `unslop-ai-code/candidates.jsonl` (1.3MB) · `candidates_posts.jsonl` (1.7MB) | 수집한 원문 |
| `analyze.py` · `analyze_comments.py` · `calibrate.py` | 집계 코드 |
| `chart_*.png` 10장 | 서브레딧별·연도별·항목별 분포 |
| **`skill/scripts/devibe_scan.py`** | **코드베이스를 훑어 신호를 잡아내는 검사기** |
| `skill/references/tells.md` (18KB) | 항목별 근거·코드 패턴·수정법 |

즉 **검사기가 이미 존재한다.** 앞 문서에서 "점수제 말고 기계 검사로 가자"고 쓴 것을
남이 이미 만들어 뒀다. 표준 라이브러리만 쓰고 경로 하나만 받는다.

### 1-2. GPT 요약이 빠뜨린 것 — 2026년 1위 신호

원자료 목록의 **0번 항목**이 GPT 요약에 없다.

> **크림색 배경 + 세리프 제목(Instrument Serif·Fraunces·Playfair) + 세이지 그린 강조**

저장소가 이걸 왜 1위로 올렸는지가 중요하다. **이전 세대의 안티-AI 조언이 수렴한
결과물이라서**다. 보라색 그라디언트는 대놓고 기본값처럼 보였지만, 이 조합은 «취향처럼
보이는 기본값»이라 들켰을 때 반응이 더 나쁘다는 것이다.

**이게 지금 우리 상황에 그대로 걸린다.** 안티-AI 하네스를 만들어 그대로 따르면
「하네스를 따른 티」가 다음 신호가 된다. 하네스가 스스로를 무효화하는 경로다.

대응은 하나뿐이다 — 규칙을 늘리는 게 아니라 **기존 자산에 고정하는 것**.
EASWA 에는 이미 고정할 것이 있다: 다크 `#0b0e14` + 주황 `#e8722a` + Pretendard.

### 1-3. 퍼센트의 분모가 3.2백만이 아니다

`DATA_NOTE.md` 를 읽고 확인했다.

- 퍼센트는 **주제 관련 댓글 3,033건 중의 비율**이다. 3,214,533건이 분모가 아니다.
  1위 항목 2.5% ≈ 약 76건이라는 뜻이다.
- 저장소가 직접 밝힌 한계: 수집 기반 집계는 최선 추정치이고, 아카이브가 큰 서브레딧에서
  응답을 못 줘 일부만 있다. 항목 순위는 그 분모와 무관하게 계산된다.
- 성격 규정도 저자가 직접 했다 — **말수 많은 온라인 여론의 대리 지표**이지 개발자
  전체나 코드 전체의 측정이 아니다.

GPT 근거자료는 "상대적 우선순위로 사용한다"는 경고는 옮겼지만 **분모를 안 적었다.**
그 상태로 하네스 §2.2 에서 −10 / −9 / −8 가중치로 바뀌었다.

### 1-4. 「쫓지 말 것」 목록이 따로 있다

원자료 12절이 검증 후 **기각한** 항목들이다. GPT 하네스가 일부만 옮겼다.

| 항목 | 원자료 판정 |
|---|---|
| 메시·오로라 배경 | 기각 — 키워드 오탐이었다 (`/blob/` URL 등) |
| 벤토 그리드 | 0.1% 로 꼴찌, 옹호하는 사람도 많다. 신호 아님 |
| **다크 모드 자체** | **신호 아님.** 문제는 «이유 없는 글로우»뿐 |
| **shadcn·Tailwind 자체** | **신호 아님.** 기본값을 그대로 쓰는 게 문제 |

세 번째가 EASWA 에 직접 걸린다. **다크 기조는 그 자체로 감점 요인이 아니다.**
GPT 시안이 홈을 밝게 바꾼 근거가 이 조사에는 없다.

## 2. 같은 조사를 Hacker News 에서 다시 돌렸다

원자료는 Reddit 한 곳이다. 다른 커뮤니티에서도 같은 순서가 나오는지 봐야
믿을 수 있다. Hacker News 공개 검색 API 로 2023년 이후 댓글을 모았다.

- 수집 2,836건 → **주제 관련 981건** (디자인 낱말과 AI 낱말이 함께 나온 댓글)
- 연도별 — 2023년 36 · 2024년 30 · 2025년 119 · **2026년 796**
- 지표는 원자료와 같게 맞췄다: 주제 관련 댓글 중 그 항목을 언급한 비율

| 항목 | Reddit 3,033건 | **HN 981건** |
|---|---|---|
| shadcn·Tailwind 기본값 | 2.5% (1위) | **8.3% (1위)** |
| 그라디언트 | 2.0% (3위) | **2.8% (2위)** |
| 보라·인디고 | 2.3% (2위) | **2.4% (3위)** |
| 과한 애니메이션 | 약 1.1% (4위) | **2.0% (4위)** |
| 다 똑같이 생겼다 | — | 1.2% |
| 크림+세리프+세이지 | (0번, 순위 밖) | **1.0%** |
| 기본 폰트 | 0.4% | 0.8% |
| 글로우·네온 | 0.7% | 0.4% |
| 전부 둥근 모서리 | 0.8% | 0.3% |
| 글래스모피즘 | 0.2% | 0.3% |
| 이모지 아이콘 | 0.5% | 0.2% |
| 히어로+3카드 | 0.4% | 0.1% |
| 벤토 그리드 | 0.1% | **0.0%** |

**상위 네 개의 순서가 그대로 재현됐다.** 벤토가 양쪽 다 바닥인 것도 같다.
독립된 두 커뮤니티에서 같은 순서가 나오므로 **순위는 근거로 쓸 만하다.**

한계는 분명히 적어 둔다 — 검색어가 원자료와 다르고, 주제 검색이라 전수가 아니며,
2026년이 796/981 로 몰려 있고, HN 은 개발자 쪽으로 기운다.

### 그런데 이 표가 가중치 점수제를 무너뜨린다

표 아래쪽을 보면 **「간격이 제멋대로다」 0.0% · 「정보 위계가 없다」 0.3%** 다.
원자료도 이 둘을 "정규식으로는 못 잡는다"며 별도 절로 뺐다.

여기서 갈린다. **말로 이름 붙이기 쉬운 것(색·프레임워크 이름)은 많이 언급되고,
눈으로만 잡히는 것(밀도·위계·정렬)은 거의 언급되지 않는다.**
언급 빈도를 그대로 감점 가중치로 쓰면 **후자를 0점으로 취급하게 된다.**

그런데 이 프로젝트에서 소유자가 실제로 세 번 지적한 것이 전부 후자다 —
*"이게 제일 별로임 ai같음"* 이라고 폐기시킨 작은 카드 격자, 밀도, 선택 표시 방식.
**커뮤니티가 못 세는 항목이 여기서는 1순위다.** 그래서 점수제가 아니라
통과·불통과 목록이어야 한다.

## 3. 검사기를 시안이 아니라 실제 앱에 돌렸다

앞 문서의 결론이 하나 뒤집힌다. 조사 대상을 잘못 잡았던 것이다.

| 대상 | 결과 |
|---|---|
| **`frontend/src` (실제 앱, 135파일)** | **36건 — 높은 심각도 0, 중간 36** |
| `landing/zoviz` | 8건 |
| GPT 시안 v2 | **0건 — 잡힌 것 없음** |

시안은 이미 깨끗했다. **손봐야 할 것은 실제 앱 쪽에 있었다.**

### 3-1. 진짜 결함 — 주황 글로우가 아직 남아 있다

```
frontend/src/index.css:3313
.transit-step-circle.current {
  box-shadow: 0 0 14px rgba(232, 114, 42, 0.35);
}
```

`--shadow-glow` 토큰은 정말로 지워졌다(현재 0건). 그런데 **하드코딩된 주황 글로우가
따로 살아 있다.** 위치는 Transit 탐구의 «현재 단계» 표시 원이다.

이건 세 곳과 어긋난다 — `ZOVIZ_DESIGN_MIGRATION.md` §2 의 «글로우 삭제»,
`TRACK.md` 의 보완 1차 «글로우 삭제» 완료 보고, 그리고 전역 금지 목록.
**토큰만 지우고 실제 선언은 안 지운 것이다.**

노란 글로우도 둘 있다 — `.transit3d-scrubber` 손잡이 (`0 0 6px rgba(251,191,36,.5)`,
11131·11141행). 슬라이더 손잡이라 기능성 여지는 있지만 글로우는 글로우다.

### 3-2. 홈 화면이 이모지를 아이콘으로 쓴다

```
frontend/src/components/pages/HomePage.tsx:11,16,21
icon: '🔭'  ·  icon: '📈'  ·  icon: '🎓'
```

검사기는 하나만 잡았지만 실제로는 셋이다. `ui_ai_tells` 메모리가 금지한 패턴이고,
커뮤니티 조사에도 양쪽 다 올라 있다(Reddit 0.5% · HN 0.2%). **첫 화면이다.**

### 3-3. 주 버튼에 화살표가 붙어 있다

```
HomePage.tsx  ctaStart: { ko: '탐구 바로 시작 →' }
```

`ui_ai_tells` 의 «지시형 어투 + 화살표» 항목이고, 원자료 목록에도 화살표 접미 링크가
들어 있다.

### 3-4. 오탐이라 손대면 안 되는 것

정직하게 갈라 둔다. 검사기 36건 중 대부분은 결함이 아니다.

- **알약 모서리 32곳** — 선택자를 전부 확인했다. `obs-badge`·`module-row-chip`·
  `kmt-site-chip`·`page-chip`·`*-node`(점)·`navbar-menu-toggle span`(햄버거 줄) 처럼
  **의미상 알약이 맞는 것들**이다. 하네스도 이런 자리는 허용한다. 손대지 않는다.
- **검은 그림자 2곳** — `text-shadow: 0 1px 3px rgba(0,0,0,.7)` 은 사진 위 글자
  가독성용 그림자다. 네온 글로우가 아니다.
- **`0 0 0 Npx` 세 곳** — 번짐 반경이 0 이라 테두리 링이다. 글로우가 아니다.

## 4. 축 2 — 비교 대상이 처음부터 틀렸다

GPT 하네스 §4 는 EASWA 를 **NASA Exoplanet Archive · SDSS SkyServer · ESASky ·
SIMBAD** 와 비교한다. 전부 **연구자용 자료실**이다.

EASWA 는 자료실이 아니라 **학습 환경**이다. 그 분야엔 별도의 문헌군이 있고,
GPT 근거자료에는 한 편도 없다.

### 4-1. Quintana 외 (2004) — 이게 EASWA 설계 원리의 원본이다

> Quintana, C., Reiser, B. J., Davis, E. A., Krajcik, J., Fretz, E., Duncan, R. G.,
> Kyza, E., Edelson, D., & Soloway, E. (2004). A Scaffolding Design Framework for
> Software to Support Science Inquiry. *The Journal of the Learning Sciences*, 13(3),
> 337–386.

PDF 전문을 받아 표 1 을 그대로 확인했다. 과학탐구를 세 부분으로 나누고
7개 지침 · 18개 전략을 준다.

| Quintana 지침 | EASWA 의 어디 |
|---|---|
| 1. 학습자의 이해에 다리를 놓는 표현과 언어 (1a 시각적 개념 조직자 · 1b 직관을 딛는 설명 · 1c 내용 적용 안내) | 설계 원리 3(가시화). **영문 용어 154건 문제가 정확히 1b 위반이다** |
| 2. 도구와 산출물을 학문의 의미 구조에 맞춰 조직 | 탐구 흐름 자체가 브랜드라는 결론과 같다 |
| 3. 여러 방식으로 들여다볼 수 있는 표현 (3a 속성이 드러나는 표현 · 3b 같은 대상의 여러 관점 · 3c 직접 주무를 수 있는 표현) | 광도곡선·구경 조절·비교성 확인. **3b 가 「측정값과 기준값을 한 화면에」 요구의 근거다** |
| 4. 복잡한 과제에 구조를 준다 (4a 경계 설정 · 4b 과제 분해 · 4c 기능 모드로 활동 공간 제한) | **Step 1–6 과 입문·심화 분기가 정확히 이것이다** |
| 5. 과학적 실행에 대한 전문가 안내를 심는다 (5a 특징 · 5b 그렇게 하는 이유) | 설계 원리 3(블랙박스 금지, 분석 조건·모델 가정 노출) |
| 6. 눈에 안 띄는 반복 작업은 자동으로 처리 (6a 인지 부담 감소 · 6b 산출물 정리 · 6c 도구 간 이동) | **설계 원리 2(기술 실행 부담 완화)가 곧 6a 다** |
| 7. 탐구 중 표현과 성찰을 계속 하게 한다 (7a 계획 · 7b 점검 · 7c 의미 만들기 중 표현 · 7d 지식의 성격 드러내기) | 설계 원리 4(해석은 학습자가) + Step 6 기록 |

**EASWA 의 5개 설계 원리가 이 7개 지침과 거의 일대일로 대응한다.**
지금까지 자체 도출로 서 있던 원리에 표준 인용이 붙는다는 뜻이고, 논문 3장에도 쓸 수 있다.

동시에 **가장 얇은 칸도 보인다** — 3c(직접 주무르는 표현)와 7a·7b(계획·점검 안내).
7 계열은 이미 «학생 어려움 1위»로 잡혀 있던 6단계 기록과 같은 자리다.

### 4-2. Skarlatidou 외 (2019) — 시민과학 기술 설계 지침, 62편 체계적 문헌고찰

> Skarlatidou, A., Hamilton, A., Vitos, M., & Haklay, M. (2019). What do volunteers
> want from citizen science technologies? A systematic literature review and best
> practice guidelines. *JCOM*, 18(01), A02. https://doi.org/10.22323/2.18010202

844건을 걸러 62편을 종합한 지침이다. GPT 근거자료의 Zooniverse 블로그 한 편보다
훨씬 단단하고, EASWA 에 바로 걸리는 항목이 셋 있다.

1. **익숙한 이름을 쓸 것** — 영문 용어 154건 문제와 같은 항목이다. 문헌 근거가 생겼다.
2. **튜토리얼은 건너뛸 수 있게, 나중에 다시 열 수 있게** — Zooniverse 설문 결론과
   같은 방향이고, 이쪽은 62편 종합이다.
3. **관측을 제출하면 제출됐다는 확인을 줄 것** — **EASWA 와 어긋난다.**
   현재 기록은 제출 버튼 없이 4초 디바운스로 시트에 자동 저장된다
   (`project_anon_record_sink` 메모리). 저장됐는지 학습자가 알 방법을 확인해야 한다.

### 4-3. WISE — 같은 장르의 최대 선례

Web-based Inquiry Science Environment. Linn·Slotta 의 «비계로 지식을 통합한다»
프레임 위에 세워졌고, 연간 교사 5,000명 이상·학생 25만 명 이상이 쓰며 7개 언어를 지원한다.
탐구 지도·힌트·프롬프트를 화면 안에 심는 방식이 EASWA 의 단계 안내와 같은 계열이다.

EASWA 관련연구 절에 이미 인접 선례 목록이 있지만(`project_related_work_precedents`),
**설계 근거로서의 WISE 와 Quintana 는 빠져 있다.**

### 4-4. 천문 교육 쪽은 새로 나온 게 없다

실데이터 기반 천문 수업 도구(Hands-on Universe·SalsaJ, LCO, NITARP, Unistellar 연계
교사연수)를 훑었지만 **인터페이스 설계 근거로 쓸 만한 사용성 연구는 못 찾았다.**
이 계열은 「무엇을 가르쳤나」 보고가 대부분이다. 기존 관련연구 목록에서 더 늘릴 게 없다.
