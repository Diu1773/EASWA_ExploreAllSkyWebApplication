# 논문 스킬 구현 계획 (2026-09-14)

**목표 한 줄** — 다음 논문 첫날에 「이 프로젝트 논문화해 줘」라고 하면 고정문서 초안이 나오고,
절을 쓰면 검사가 돌고, 고치면 뜻이 새지 않는다.

**원칙 셋** — 있는 것 위에 얹는다(새 레포·새 하네스 없음) · 단계마다 EASWA 를 정답지로
삼는 시험이 있다(통과 못 하면 다음 단계로 안 간다) · 「했다」 전에 무엇을 읽었는지 찍는다.

---

## 0. 왜 「제대로 되는 게 없다」고 느끼나 — 사실만

| 있는 것 | 상태 |
|---|---|
| paper-kr 스크립트 13개 | 돈다. **그런데 설정이 v18 을 가리켜 지금 명령만 치면 옛 원고를 검사한다** |
| 게재 논문 267편 기준선·어휘 색인 | 있다. 어제 만들었다 |
| Research OS `intake scan` | 돈다. 파일 400개를 종류별로 분류한다. **수치·절차는 못 뽑는다** |
| Research OS literature hook | 이 세션에서 271번 돌았고 169번 매치가 있었다. **스킬 작업 턴에도 매번 떠서 소음이다** |
| 고정문서 | EASWA 것 5만 자. 손으로 5개월 쌓았다. **다른 논문엔 못 쓴다** |
| 회고 86건 | 어제 묶었다 |
| 회귀 대조 · 맞춤법 · 용어 일관성 · 서지 검증 스크립트 | **없다** |
| korean-academic-engine | 설계 문서만. 코드 0줄 |

**도구가 없는 게 아니라 이어져 있지 않다.** 열세 개가 각자 돌고, 다음 논문에 가져갈 수 있는
건 그중 절반이다. 그래서 새로 만들지 않고 **잇는다.**

## 1. 단계 — 여섯, 각각 시험이 있다

시간은 집중 작업 기준이다. 학회(9/18~19) 뒤 9/20 부터 시작하면 10월 첫 주에 끝난다.

### Phase 0 · 잇기 (반나절)

무엇을 한다
- 검사기 13개가 **첫 줄에 「무엇을 읽었나」**를 찍는다 — 파일명 · 문장 수 · 절 수
- 설정 파일 하나(`논문설정.json`)가 v19 를 가리키게 하고, 모든 검사기가 그것만 본다
- `--json` 옵션으로 `Issue[]` 를 낸다 (id · span · text · category · severity · evidence · message)

시험
```bash
for f in check_*.py; do python -X utf8 $f --json | head -1; done
```
**13개 전부 첫 줄이 `EASWA_논문_v19.md · 문장 N · 절 M` 이어야 통과.** 하나라도 v18 이면 실패.
(F-310·F-312 — 검사기가 옛 원고·빈 범위를 보고 「0건」 낸 것이 이걸로 막힌다)

### Phase 1 · 회귀 대조 (1일) — 가장 아픈 것부터

무엇을 한다
- `check_meaning_drift.py 전.md 후.md`
- 방어 표지 문장(일반화 · 한정 · 않는다 · 확인하지 않았다 · 수 있다 · 시사한다 · 해야 한다)을
  문장 단위로 짝 짓고 **사라진 것 · 극성이 바뀐 것 · 세진 것**을 표로 낸다

시험 — **정답지가 이미 있다.** 2026-09-12~14 백업 19개를 시간순으로 놓으면 방어 표지가
줄어든 쌍이 10개다.

| 쌍 | 줄어든 것 |
|---|---|
| `204049 → 2장codex전` | 「확인하지 않았다」 1 → **0** · 「한정」 2 → 1 |
| `2장전 → 5.1재작성전` | 「해야 한다」 13 → 10 · 「않는다」 9 → 8 |
| `문체전 → 5장전` | 「한정」 5 → 3 |

**첫째 쌍의 「확인하지 않았다」 소실을 잡고, 그 문장이 정말 사라졌는지 사람이 확인해서
맞으면 통과.** 열 쌍 전부 돌려 오탐(줄었지만 뜻은 같은 것)이 몇 건인지 함께 적는다.

### Phase 2 · 문안 제안 (반나절)

무엇을 한다
- `check_wording.py --propose` — 짚은 자리마다 대체어 셋 + 267편 편수
- 대체어는 색인에서 **같은 기능·같은 뿌리 계열**로 고른다 (썼다 → 사용하였다)

시험
어제 손으로 낸 `문안후보_2026-09-13.md` 14자리와 대조한다. **권한 대체어가 스크립트의
셋 안에 드는 비율.** 절반을 넘으면 통과, 못 넘으면 고르는 규칙을 고친다.

### Phase 3 · 규칙 통합 + 맞춤법 + 용어 (1일)

무엇을 한다
- `measure_rules.py` — 외부 규칙을 267편에 재서 `measured.json` 을 만든다
  - paper-proofread `rules_ko.md` 21개 (어제 실측: 10 신호 · 4 잡음 · 2 틀림)
  - DaleSeo `grammar-checker/references/common-errors.md` 맞춤법 표
  - humanize-korean 70개 패턴 (「~적」 100% · 「~고 있다」 91% 는 폐기될 것이다)
- `check_ko_rules.py` — **살아남은 규칙만** 적용. 출력마다 「267편 중 N편」
- `check_terminology.py` — 같은 말의 띄어쓰기·표기 혼용 (어제 「기준 값」·「탐구 모듈」 잡은 것)

시험
- `measured.json` 에서 **함으로써(56.6%)·매우(76.0%) 가 폐기되고 시켜지다(0%) 가 살아야** 통과
- `check_terminology.py` 가 v19 에서 「기준 값」 278행 · 「탐구 모듈」 54행을 잡아야 통과

라이선스 — paper-proofread · DaleSeo 는 MIT 라 규칙을 가져오고 고지를 남긴다.
**`nyjin/humanizer-ko` 는 라이선스가 없어 쓰지 않는다.**

### Phase 4 · 고정문서 생성기 (2일) — 다음 논문의 핵심

무엇을 한다
- 입력: Research OS `intake --action scan` 결과(파일 분류) + 사용자 메모 세 줄
  (왜 했나 · 어디에 내나 · 무엇을 보이고 싶나)
- 레포에서 뽑는다
  - **가진 자료** — `RESULTS_*.md` · 설문 CSV · 로그 · 분석 리포트. 파일 경로까지
  - **고정 수치** — 결과 파일 안의 N · 비율 · 중앙값
  - **연구 절차** — 커밋 이력에서 「언제 무엇이 생겼나」
  - **못 하는 주장** — 자료 목록의 **여집합**. 사전·사후 점수가 없으면 학습 효과 금지
- 출력: `논문_고정문서_초안.md`. **사람이 확인하기 전까지 초안이다.**

시험 — **정답지가 있다.** EASWA 레포에 돌려 실제 `논문_고정문서.md` 와 대조한다.

| 항목 | 정답 | 통과선 |
|---|---|---|
| 가진 자료 | D1~D7 | 5개 이상 맞힘 |
| 고정 수치 | 6개 (현직 12 · 완주 9/12 · 익명 18 · 적합 14 · 반지름비 0.1457 · WASP-121b −12%) | 4개 이상 |
| 못 하는 주장 | 6개 | 4개 이상 |
| 연구 절차 | 1차 검토 07-24 · 2차 09-06~07 | 날짜 둘 다 |

### Phase 5 · 장·절 뼈대 + 절 초안 (2일)

무엇을 한다
- 투고처 양식 파일 — `venues/현장과학교육.json` (6장 모래시계 · 절 역할 · 분량 · 참고문헌 꼴)
- 절을 쓰기 전에 **그 절이 쓸 수 있는 사실**을 고정문서에서 뽑아 보여 준다
- SKILL.md 11-0-A(267편이 쓰는 종결·리듬·길이)를 읽고 초안을 쓴다
- 쓴 직후 Phase 0~3 검사가 자동으로 돈다

시험
고정문서와 양식만 주고 **5.3 을 새로 쓴다.** v19 의 5.3 과 나란히 놓고 검사기 점수
(리듬 자리 · 낯선 말 수 · 역할 위반)를 비교하고, **사장님이 읽고 어느 쪽인지 못 가리면 통과.**
가리면 무엇이 달랐는지 적고 11-0-A 를 고친다.

### Phase 6 · 서지 검증 스크립트화 (반나절)

무엇을 한다
- `check_refs_exist.py` — 어제 일회성으로 돌린 것을 스크립트로
  - `published-print` 우선 · 제목 전체 파싱 · arXiv 번호 직접 조회 · 국문은 KCI 시도
  - 미확인은 「매체 종류」를 붙여 낸다 (단행본 · 보고서 · 블로그)

시험
v19 참고문헌 61건 → **영문 실존 44 · 미확인 8 · 환각 0** 이 재현되어야 통과 (F-333 의
오탐 22건이 다시 나오면 실패).

## 2. 안 하는 것

| | 왜 |
|---|---|
| 새 레포 `korean-academic-engine` | paper-kr 안에서 자란다. 이름은 Phase 5 끝나고 값이 증명되면 바꾼다 |

| `vendor/` 통째 복사 | 규칙만 실측해서 `measured.json` 으로. 원본은 링크 |
| 벡터DB · 파인튜닝 · LangGraph | JSONL + Python 으로 충분하다 |
| Research OS literature hook 손보기 | 별개 문제다. 이 계획은 `intake scan` 만 쓴다 |
