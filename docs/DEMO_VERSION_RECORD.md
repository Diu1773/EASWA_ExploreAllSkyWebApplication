## 2차 코호트 — 예비 교사 (예정)

**동일 산출물 원칙**: 예비교사 시연까지 `frontend/`·`backend/` 코드를 변경하지 않는다.
보완은 두 코호트 자료를 모두 수집한 뒤 1회로 수행한다(논문 §4.6).

시연 실시 후 아래 표를 채울 것:

| 항목 | 값 |
|---|---|
| 진행 일시 | [시연 후 기입] |

| 첫/마지막 제출 시각 | [로그에서 확인] |
| 설문 응답 수 | [기입] |

**만약 부득이하게 코드를 변경한 경우**(치명적 장애 등)에는 변경 커밋과 사유를 여기에 반드시 기록하고,
논문 §3.1의 "동일한 산출물" 서술을 그 범위만큼 수정한다(예: "접속 장애 수정 외 기능 변경 없음").
