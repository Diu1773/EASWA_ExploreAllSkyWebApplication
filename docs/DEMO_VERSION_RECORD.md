1. **모서리** — `border-radius` 선언 276개 중 212개를 `var(--radius-sm)`로 통일하고
   토큰 `--radius-sm/md/lg`를 모두 `0`으로. 완전 원(`50%` 27개)·알약(`999px` 35개)은 유지.
   칩 3종(`.kmt-type-chip`·`.kmt-list-chip`·`.kmt-popup-type-badge`)은 20px/16px에서
   `999px`로 올려 배지 규칙에 합류시켰다.
   → 탐구블럭 Step 0 실측: 모서리 값 **10종 → 2종**(`50%`, `999px`), 중간값 0종.
2. **대표 탐구 질문 블록** — 주황 테두리+주황 배경 → 중립 톤 면 1단계, 라벨은

3. **`--text-muted`** — `#6b7585` → `#98a2b3`. 카드 위 명암비 3.49(WCAG AA 미달) → 6.31.
   시안에 포함돼 있던 값이라 함께 반영했다.
