## 2. ★ 실제 버그 — 860px 이하에서 H1 띄어쓰기가 깨진다

화면에 이렇게 보인다:

> 공공 천문자료**로외계**행성을 직접 / 분석하**는탐구** 플랫폼

원인:

```html
<h1 class="home-hero-title">공공 천문자료로<br>외계행성을 직접 분석하는<br>탐구 플랫폼</h1>
```
```css
@media (width <= 860px) { .home-hero-title br { display: none; } }
```

`<br>` 자리에 **공백 문자가 없다.** 데스크톱에서는 `<br>`이 줄을 나눠 멀쩡하지만,
860px 이하에서 `<br>`이 `display:none`이 되면 **문자열이 그대로 붙는다.**

- 영향 범위: **태블릿·모바일 전 구간** (대상이 학생·교사라 모바일 비중 높음)
- 위치: 랜딩 첫 화면 최대 글자
- 이건 CSS/디자인이 아니라 **콘텐츠 결함**이라 어떤 자동 검사로도 안 잡힌다

**수정**: `<br>` 앞뒤에 공백을 넣거나(JSX면 `{' '}`), `br { display:none }` 대신
`br::before { content: " " }` 로 대체. **다른 `<br>` 숨김 지점도 같은 패턴인지 훑을 것.**

## 3. 토큰 규율 — 설계는 좋고 준수가 나쁘다

`frontend/src/index.css`의 `:root`는 잘 만들어져 있다:

```css
--radius-sm: 4px;  --radius-md: 6px;  --radius-lg: 10px;
--bg-primary/secondary/tertiary/card/hover   (5단계)
--text-primary/heading/secondary/muted       (4단계)
--shadow-sm/md/lg/glow, --transition-lift
--font-ui: Pretendard …  --font-mono: IBM Plex Mono
```

문제는 준수율이다:

| 항목 | 전체 선언 | `var()` 사용 | 하드코딩 | **이탈률** |
|---|---|---|---|---|
| `border-radius` | 276 | 81 | 195 | **71%** |
| `color` | 730 | 617 | 113 | 15% |

**왜 radius만 무너졌나** — 색은 `var(--accent)`를 안 쓰면 눈에 띄게 틀리므로 강제된다.
radius는 14px이든 16px이든 **그 자리에서는 멀쩡해 보인다.** 틀린 게 한 화면에
모였을 때만 드러난다. LLM은 컴포넌트를 하나씩 독립적으로 만들면서 전역 규칙을
매번 참조하지 않으므로, 이 축이 가장 먼저 무너진다. **AI 코딩의 지문이다.**

### ⚠️ 앞선 과장 정정
초기에 "radius 23종"이라고 했으나 그건 **스타일시트 전체 선언** 기준이다.
**랜딩 화면 렌더 기준으로는 6종**이고, 그중 3종(6/4/10px)은 정상 토큰이다.
토큰 밖은 `8px×6 · 14px×3 · 16px×1` = **10개**. 한 화면에 23종이 보이는 게 아니다.

## 4. 레퍼런스 — 추천만 하지 않고 같은 지표로 측정함

| 사이트 | 요소 수 | **radius 종류** | 폰트 | 그라디언트 | 컬러글로우 | 이모지 |
|---|---|---|---|---|---|---|
| **Our World in Data** | 1,572 | **3** | 2 (Lato + Playfair) | 0 | 0 | 0 |
| **NASA Science** | 2,612 | **3** | 3 | 12 | 2 | 0 |
| **Zooniverse** | 392 | **5** | 3 (Karla) | 5 | 0 | 0 |

| ESASky | 2,121 | 11 | 5 | 5 | 0 | 0 |

**밀도로 읽어야 한다.** Our World in Data는 **1,572개 요소를 radius 3종으로** 처리한다.
EASWA는 134개를 6종으로. 12배 많은 요소를 절반의 규칙으로 다루는 것이 규율이다.

### 🥇 [Our World in Data](https://ourworldindata.org) — 규율 레퍼런스
공공 데이터를 일반인이 탐구하게 만든다는 **목적이 같다.** 그라디언트 0 · 글로우 0 ·
glass 0 · 이모지 0 · 폰트 2종.
**훔칠 것**: ① 차트가 주인공이고 UI가 사라지는 배치 ② 본문 세리프 / UI 산세리프 역할 분리
③ 장식 0 — 데이터 자체가 시각적 흥미를 담당.

### 🥈 [Zooniverse](https://www.zooniverse.org) — 교육 톤 레퍼런스
시민과학 플랫폼, 백악관 오픈사이언스상 수상. "학생·시민이 실제 연구에 참여"라는
EASWA 포지션과 같다. **이모지 0개로 친근함을 낸다** — `🔭📈🎓` 자리를 대체할 방법.

### 🥉 [ESASky](https://sky.esa.int) · [Aladin Lite](https://aladin.cds.unistra.fr) — 도메인 트윈
**기능 레퍼런스이지 디자인 레퍼런스가 아니다.** radius 11종, 폰트 5종
(`Arial`과 `arial`이 따로 셀 만큼 관리 안 됨), 폰트 크기 14종.
"천문 기관이 만들었으니 따라가자"는 함정.

> **그래도 하나는 훔칠 것** — 첫 화면 모달의 `Choose a mode: Science / Explorer`.
> 전문가와 입문자를 진입점에서 가르는 구조. EASWA의 **학생 / 교사 / 연구자** 문제에
> 그대로 대응한다. 못생긴 UI에서도 구조는 훔칠 수 있다.

### 참고 — [NASA Science](https://science.nasa.gov/exoplanets/)
radius 3종으로 2,612 요소를 처리하는 규율은 훌륭하다. 다만 **Inter를 1,752개 요소에 쓴다**
— 슬롭 패턴 ①번 그 폰트다. 그런데 아무도 NASA를 AI라고 안 한다.

> **교훈: "Inter = AI 티"는 법칙이 아니라 휴리스틱이다. 개별 패턴이 아니라
> 히트 개수와 일관성이 판정한다.**

## 6. 재현 방법

```bash
# 빌드를 로컬 서버로 띄운다 (dist는 SPA라 루트 서빙 필요)
python -X utf8 -m http.server 8778 --directory frontend/dist
```

브라우저 콘솔에 붙여넣으면 위 표의 수치가 나온다:

```js
(() => {
  const vis = [...document.querySelectorAll('body *')].filter(el => {
    const cs = getComputedStyle(el); return cs.display!=='none'&&cs.visibility!=='hidden'; });
  const cs = el => getComputedStyle(el);
  const radii = {}, fonts = {};
  vis.forEach(el => {
    const r = cs(el).borderRadius;
    if (r && r !== '0px' && !/%|9999|999px/.test(r)) {
      const v = r.split(' ')[0]; radii[v] = (radii[v]||0)+1; }
    const f = cs(el).fontFamily.split(',')[0].replace(/["']/g,'').trim();
    if (f) fonts[f] = (fonts[f]||0)+1; });
  const EMOJI = /\p{Extended_Pictographic}/u;
  return {
    elements: vis.length,
    radiusKinds: Object.keys(radii).length,
    radiusTop: Object.entries(radii).sort((a,b)=>b[1]-a[1]),
    fonts: Object.entries(fonts).sort((a,b)=>b[1]-a[1]).slice(0,4),
    gradients: vis.filter(el=>/gradient/.test(cs(el).backgroundImage)).length,
    coloredGlow: vis.filter(el=>{const b=cs(el).boxShadow;
      return b!=='none'&&!/rgba?\(0,\s*0,\s*0/.test(b);}).length,
    uppercase: vis.filter(el=>cs(el).textTransform==='uppercase').length,
    glass: vis.filter(el=>{const b=cs(el).backdropFilter; return b&&b!=='none';}).length,
    emoji: vis.filter(el=>EMOJI.test([...el.childNodes]
      .filter(n=>n.nodeType===3).map(n=>n.textContent).join(''))).length,
  };
})()
```

**정적 grep으로 세지 말 것.** CSS 선언에는 있는데 실제로 적용되는 요소가 없는 경우가
많다. AstralImage 사이트에서 정적 검사로 "그라디언트 11건·글로우 14건"이 나왔지만
계산된 스타일에서는 **0건·1건**이었다. Krebs 연구가 스크린샷 LLM 판정 대신
결정론적 DOM 검사를 쓴 이유다.

하나도 없다. 카드가 기본값이면 카드는 아무 정보도 주지 못한다.

  `플랫폼 · 비교성 선택` `플랫폼 · ROI 선택` `내가 판단`)
- **kicker 라벨 12개** — 전부 `#e8722a` · 12.24px · letter-spacing 0.98px · uppercase

kicker 3종(`분석은 이렇게 흘러갑니다` `이 탐구에서 할 일` `수업 적용`)은 **색·크기·자간·
변형이 완전히 동일**하다. 위계가 아니라 반복이다. 그리고 `text-transform: uppercase`는
**한글에서 아무 일도 하지 않는다** — 영어 SaaS 랜딩의 eyebrow 관습을 검사 없이 한국어에
옮긴 자국이다. §1의 ⑩(H1 위 배지)·⑯(대문자 라벨)이 탐구 화면에서 12배로 복제됐다.

### 8.4 ★ 번호 체계가 두 개 겹친다

같은 화면에 원형 숫자 배지가 **14개**, 서로 다른 두 체계다.

| 체계 | 범위 | 지름 | 글자 | 의미 |
|---|---|---|---|---|
| `transit-step-circle` | **0–6** | 36px | 16px | 탐구 단계(내가 어디 있나) |
| `transit-pipeline-num` | **1–7** | 28px | 14px | 분석 파이프라인(무슨 일이 일어나나) |

지름 차이 8px, 모양은 둘 다 정원. 학습자는 "4단계"가 스텝퍼의 4인지 파이프라인의 4인지
구분할 근거가 화면에 없다. **AI 티 이전에 스캐폴딩 결함이다** — 설계원리 ③(분석 과정의
가시화)을 지키려고 넣은 파이프라인이 원리 ⑤(단계 흐름)의 번호와 충돌한다.

### 8.5 3개 모듈이 같은 골격을 반복한다

`exoplanet-transit` · `cluster-cmd` · `kmtnet` Step 0 캡처를 겹쳐 보면 동일하다:

```
헤더 카드(뒤로가기 + h1 + 설명) → 스텝퍼 → Step 패널
  → 매체(3D/사진/영상) → [이 탐구에서 할 일] [수업 적용] 2열 카드 → 푸터
```

2열 카드 쌍은 `InquiryLayout.tsx:432-453`의 **한 컴포넌트**라 코드 중복은 아니다.
문제는 **모듈마다 다른 건 글자뿐**이라는 점이다. 성단 모듈에는 CMD 두 장이 주인공인데
그 아래에 외계행성 모듈과 똑같은 회색 2열 카드가 붙는다. 랜딩의 ⑫(아이콘 카드 반복)이
탐구 화면에서 **모듈 간 반복**으로 재현된다.

### 9.1 구두점 지문

**em-dash 36곳이 이 층의 최대 지문이다.** 쓰임이 세 가지로 갈린다:

  ← 조사 `를`이 대시 뒤에 남아 문장이 끊긴다. **이건 결함이다**
- **문장 연결** (가장 AI스럽다) — `코딩 없이 웹에서 바로 — MAST 기반…`,
  `…밝아집니다 — 왼쪽은 광도곡선, 오른쪽은 광선 기하입니다.`

### 9.2 ★ 어미가 한 덩어리 안에서 섞인다
